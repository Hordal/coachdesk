# 제품 설계 목차

현재 설계 + 남은 결정만 정리. 설계 작성 ≠ 구현·정확도 검증 완료. 영상·전문가 수·장비 규모 미정, 현재 확보 자원으로 최종 제품 요구 제한 금지.

## 기준 자료

- 분석 분류·관찰 Feature·기술 판정 단계·처리 흐름·예상 분석 시나리오: 분석 항목 및 판정 구조
- 기본 모델 후보: 모델 후보 및 기술 검토
- 판정 기준(D)·제품(P)·기술(T) 제안안, MMA 구현안: 판정 기준·제품 결정사항 및 MMA 도입안
- 세 페이지와 이 문서 모음이 다르면 세 페이지 기준으로 이 문서 수정
- 팀 공유 문서(`공유본`): '기획 한눈에 보기', '진행 현황', '2026-10-07 결정사항(임시)'. 이 문서 모음의 요약. 이 문서 모음을 먼저 수정 → 공유 문서 반영
- 이전 공유 페이지(00 시작하기~10 연동 확인 사항): 01, 23, 27, 29~32로 이전 완료

## 읽는 순서

분석 항목 및 판정 구조 → 판정 기준·제품 결정사항 및 MMA 도입안 → 제품 목적(01) → 판정 기준 양식(02) → 판정 정의 카드 모음(02B) → 구체 예제(02A) → 처리 흐름(10) → 데이터 구조(14) → 모델 후보와 상업 이용(20A) → 기술 인식·접촉 판정(24) → Feature·규칙 형식(25) → 측정 데이터 명세(26) → 평가(18) → 남은 작업(23) → 검증·운영(31) → 그라운드 사건(33) → 결정 항목(30) → 판매(28)

## 사용 안내

- 문서 참조: 번호 + 제목. 외부 출처: 제목 + 전체 URL
- 02의 [작성]: 도메인 기준 입력란. 모델 선택·카메라 구성·성능 수치: 관련 항목의 실험으로 결정
- 02B: 02 양식에 맞춘 D01~D10 정의 카드 + 규칙 근거·관계 알고리즘·임시 기계 기준(`team-provisional-v1`) 작성 후보. 02와 별도 파일로 유지, 확정 값은 카드에서 갱신
- 02A_가상_사건_데이터.json(상대 반격), 02A_시나리오6_가상_데이터.json(반복 가드 복귀 지연): 예제용 첨부 데이터, 실제 영상 정답·운영 스키마 아님. 검사 도구·회귀 테스트: 저장소 `tools/contract_check`
- '임시': 확정 전 구현·시험용 값(예: 원본 보관 7일, 처리 구간 30초). 확정 시 교체. 업계 표준·성능 보장 아님. 서버 구현의 임시 값: 27의 10절
- 표기
  - 결정: 제품 요구 또는 채택한 공통 처리 원칙
  - 기본안: 개발 착수용 선택, 실험 결과에 따라 변경 가능
  - 미정: 기준·사례·실험 결과 후 결정(목록: 30)
  - 가상 예제: 설명용 자료, 실제 분석 결과·정답 아님
  - 초기 목표값: 근거 미확정 출발 수치, 실험으로 확정
- 문서 번호: 참조용. 14·16의 실행/정의 버전: 분석 결과 재현용 제품 데이터, 문서 변경 이력과 별개
