# 02A 공방에서 피드백까지 — 가상 예제
작성일: 2026-09-21 | 상태: 설계용 가상 자료. 실제 영상·모델 실행·전문가 판정 없음.

## 1. 예제의 범위

킥복싱 영상에서 사용자 A의 발차기 이후 상대 B의 공격·접촉 결과 연결. 공방 하나 상세 기록 + 다른 공방 네 개 추가 → 반복 집계. 수치·시각·판정: 전부 가상 값, 실제 성능·종목 판정 기준 아님.

동반 파일 `02A_가상_사건_데이터.json`(demo-0.2): 프로그램 입력으로 사용 가능한 설계 샘플.
- 14의 객체 구분(Event·Assessment·EventRelation·Exchange·Aggregate·Finding·Evidence) 준수
- 판정: 사건에 넣지 않고 질문별 Assessment로 기록. 집계: 분자·분모·미판정 참조와 함께 기록
- 사건 분류·관계·질문 코드 이름: 임시, 14의 최종 스키마 아님
- `expected_summary`: 회귀 검사용 기대값
- 영상에서 실제 추출한 데이터 아님, 추출 단계가 만들어야 할 출력의 예시

| 입력 | 이 예제의 값 |
|---|---|
| 영상 | demo-video-01, 3개 라운드 가상 원본. 총 9분(휴식 포함) |
| 대상 | A = 사용자, B = 상대. 선수 연결: 정답 가정 |
| 종목 | 킥복싱. 공식 채점·승패 추론 안 함 |
| 사건 범위 | 클린치 없는 발차기 + 뒤따른 상대 공격 |
| 피격의 표현 | 1단계 판정 범위: '접촉 있음 + 접촉 부위 머리'(가드 접촉과 구별). 충격·유효타·공식 득점과 구별 |
| 원본 시간 | 표: 분:초, JSON: 원본 시작 기준 마이크로초. 구간 [시작, 끝) |
| 실제 거리 | 입력 없음. 거리 값·구간·리치 우위 생성 금지 |

실제 거리: 제품 요구로 유지. 이 예제 = 거리 기반 습관 분석 완료 예제 아님, 그 이전 단계(행동·반응·결과 연결) 검증용.

## 2. 공방 X01을 자세히 기록하기

근거 재생 구간 가정: 00:09~00:14. 5초 = 이 공방 표시용 임시 값, 모든 사건의 공통 분석 길이 아님.

| 사건 ID | 시각 | 주체 → 대상 | 기록할 사실 | 기록하지 않을 주장 |
|---|---|---|---|---|
| E01 | 00:10.00~00:10.70 | A → B | A의 발차기 시도. 접촉 결과: 가림으로 불명확 | 발차기 성공/실패, 공식 점수 획득 |
| E02 | 00:10.75~00:11.15 | B → A | B의 펀치 시도. E01에 대한 반격으로 연결된 가상 판정 | 가까운 시각이라는 이유만으로 자동 반격 확정 |
| E03 | 00:11.02~00:11.06 | B → A | E02 중 B 글러브 ↔ A 머리 접촉(부위: 머리) 가상 사건 | 충격량·손상·다운 가능성 |

관계: `E02 counter_to E01`, `E03 contact_of E02` 별도 기록. 발차기 자체의 명중 여부가 불명확해도 뒤따른 반격·피격은 각각 판정 가능.

### 구현에서 필요한 것

| 단계 | 필요한 출력 | 이번 예제의 처리 |
|---|---|---|
| 선수 추적 | A/B, 관측 신체 부위의 소속 | 정답 가정 |
| 행동 분류 | 발차기·펀치의 주체/대상·시간 구간 | 가상 사건 제공 |
| 접촉 판정 | 접촉 여부(있음·없음·불명확), 접촉 부위(머리·몸통·다리·가드·불명확) | 가상 판정 제공 |
| 반격 연결 | 독립적인 다음 공격과 구별한 관계·근거 | 가상 관계 제공. 시간 간격만으로 구현 금지 |
| 거리 측정 | 기준점·공통 공간·크기 보정·오차 | 미제공. 거리 조건 분석 중지 |

## 3. 다른 공방을 연결한 집계 입력

각 행 = A의 발차기 한 번 기준. 상대가 여러 번 공격해도 '반격당한 발차기'는 한 번만 집계. 개별 상대 공격 수: 별도 지표.

| 공방 / 발차기 시각 | A 발차기 이후 B 반격 | 그 반격에서 A 머리 접촉 | 판단 근거의 상태 |
|---|---|---|---|
| X01 / 00:10 | 있음 | 있음 | 반격·접촉 확인 가정 |
| X02 / 00:40 | 있음 | 있음 | 반격·접촉 확인 가정 |
| X03 / 01:10 | 있음 | 없음 | 펀치가 빗나가는 과정까지 확인 가정 |
| X04 / 03:10 | 없음 | 해당 없음 | 공방 종료까지 관측 가능, 반격 없음 가정 |
| X05 / 06:10 | 판단 불가 | 판단 불가 | 발차기 이후 두 선수 가려짐 |

다섯 공방의 거리 동일 가정 금지 → '근거리에서 반복되는 습관', '특정 거리에서 더 위험' 결론 금지.

## 4. 프로그램이 계산할 결과

| 지표 | 결과 | 분모와 의미 |
|---|---|---|
| 발차기 시도 | 5회 | 이 샘플에서 확인된 A의 발차기 전체 |
| 후속 반격 판정 가능 | 4회 | X01~X04 |
| 반격이 있었던 발차기 | 3회 | X01~X03. 판정 가능 4회 중 3회 |
| 반격에서 머리 접촉 확인된 발차기 | 2회 | X01·X02 |
| 반격 시도는 있었으나 접촉 없음 | 1회 | X03 |
| 반격 없음 | 1회 | X04 |
| 후속 상황 판단 불가 | 1회 | X05. 반격 없음으로 처리 금지 |
| 반격 중 머리 접촉 비율 | 2/3 | 반격 있음 + 접촉 결과 판정 가능 발차기 3회 기준 |

- 3/4와 2/3: 서로 다른 조건의 비율
- 전체 영상의 공격 탐지 완전성 검증 없음 → 실제 제품에서는 '확인된 발차기'를 분모로 표시. 표의 5회 = 실제 모든 발차기라는 성능 주장 금지

## 5. 사용자에게 보여줄 결과 예시

> 주요 장면
>
> - 00:10 발차기 뒤 상대의 반격이 이어졌고, 00:11에 머리 접촉이 확인되었습니다.
> - 01:10 발차기 뒤 상대가 반격했지만 접촉은 확인되지 않았습니다.
>
> 반복 관찰
>
> 확인된 발차기 5회 중 후속 상황을 판정할 수 있었던 것은 4회입니다. 그중 3회 상대 반격이 이어졌으며, 2회는 머리 접촉으로 연결됐습니다. 나머지 1회는 가림 때문에 판단하지 못했습니다.
>
> 확인이 필요한 부분
>
> 발차기 이후의 대응을 우선 복기할 만합니다. 다만 거리·가드 복귀·균형 중 무엇이 피격에 기여했는지는 이번 분석으로 특정하지 못했습니다.
>
> 근거 장면: 00:10 · 00:40 · 01:10 · 03:10 · 06:10(판단 불가)

실제 영상 없음 → 위 시각 재생 불가. UI 구현 시 각각 evidence 구간에 연결.

## 6. 교정 피드백 확장

위 데이터만으로는 '손을 빨리 올려라', '거리를 더 벌려라', '균형을 고쳐라' 중 무엇이 맞는지 결정 불가. 관찰 요약: 가능. 바꿔야 할 행동 특정: 제품 목표에 미도달.

| 추가 입력 | 예시 형태 — 확정 기준 아님 | 필요한 것 |
|---|---|---|
| 교정 대상 행동 정의 | 발차기 이후 어떤 손의 어느 위치·움직임을 '가드 복귀 지연'으로 분류할지 | 02의 정의 카드 |
| 정상·예외·판단 불가 사례 | 복귀가 늦어 보여도 적절한 방어 선택인 장면 등 | 사례 제공·검토 |
| 해당 행동 관측 | E01~E02 사이에서 기준 해당 동작이 실제 확인됐는지 | 탐지·평가 |
| 피드백 적용 조건 | 같은 행동이 있어도 교정 제안을 하지 말아야 할 상황 | 기준·조건 검사 |

- 조건 충족 이후에만 전문가 검증 규칙에 따라 교정 문장 출력
- '가드 복귀 지연': 설명용 후보, 이번 예제에서 발생했다고 기록·권고 금지. 실사용 시마다 코치 검토한다는 뜻 아님
- 거리 기반 피드백: 동일 방식. M 측정 정의 → 유효한 실제 거리 관측 → 상황 그룹 → 그룹별 반복 집계. 거리 미산출: 해당 그룹 편입 금지, 거리 불명확 사례 수 기록

## 7. 이 예제로 확인할 구현 조건

- E01 공격 결과 미판정이어도 E02·E03 유효 판정 유지
- X03: 반격 횟수 포함, 머리 접촉 횟수 미포함
- X04 '반격 없음' / X05 '알 수 없음' 구별
- E03 별도 사건 기록해도 E02의 공격 시도 이중 집계 금지
- 발차기 하나에 접촉 사건이 여러 개여도 '머리 접촉 확인된 발차기'는 한 번
- 거리 값 없음 → 거리 비교·리치 우위·거리 기반 교정 문장 생성 금지
- 문장에 사용한 횟수·시각: 집계·사건 ID까지 역추적 가능
- 교정 규칙 없음 → 관찰 결과만 제공, 완성된 교정 피드백으로 평가 금지

다음 작업: 이 가상 구조를 실제 짧은 영상 한 개에 수작업 적용 → 사건 경계·접촉·반격 관계에서 전문가 합의 가능 여부 확인. 이후 같은 구조를 자동 생성하는 모델 비교.

## 8. 예상 분석 시나리오와의 관계

분석 결과 기준 형태: '분석 항목 및 판정 구조'의 예상 분석 시나리오 1~6(적절한 거리 공격 성공, 사거리 밖 공격, 하이가드 방어, 회피 후 카운터, 후퇴 중 밸런스 불안정, 반복 가드 복귀 실패). 이 문서의 발차기–상대 반격 예제 = 시나리오 4(사용자 카운터)의 반대 방향(사용자 공격 뒤 상대 반격 집계) 보조 예제, 시나리오와 별개 가상 자료.

## 9. 시나리오 6 예제 데이터

`02A_시나리오6_가상_데이터.json`: 예상 분석 시나리오 6(반복적인 가드 복귀 실패)을 상태 → 행동 → 결과 구조로 옮긴 가상 자료.
- 사용자 A의 크로스 6회마다 행동 전·후 뒷손 가드 상태 구간 참조, '뒷손 가드 복귀 지연' 판정을 질문별 판정으로 기록
- 판정 4회 있음·2회 없음 → 집계 4/6
- 반복 문제 문장·교정 문장: 기준 미검증으로 보류
- 행동 전·후 기준 시점, 복귀 지연 판정: 임의 값, D02·D07 기준 아님

확인할 구현 조건
- 행동 사건의 행동 전·후 상태 참조 끊김 없음
- 결과 판정이 행동 후 상태 변화(StateInterval 참조)를 입력으로 기록
- 집계 비율: 6회 모두 판정 가능할 때만 계산. 한 회를 판단 불가로 변경 → 분모 5·판단 불가 1 별도 표시
- 기준 없음 → 관찰·집계 문장만 생성, 반복 문제·교정 문장 보류

- 시나리오별 필요 판정·선행 조건·일부 보류 시 제공 가능 내용: 29의 4절
- 시나리오 6의 66.7%: 6회 모두 복귀 여부 판정 가능할 때만 계산. 가드 복귀 지연 기준(D02·D07) 확정 전 반복 문제·교정 방향 확정 금지
