# 10 기능 간 의존성
상태: 처리 흐름 기본안. 구현·정확도 미검증.

## 처리 관계
기준 흐름('분석 항목 및 판정 구조'): 포즈 추적 → 상태 판정 → 행동 판정 → 결과 판정 → 시간 흐름 기반 사건 정리 → 반복 패턴 분석 → 사용자 피드백. 아래는 그 앞의 영상·선수 처리 단계를 더한 구현 순서. 단계별 모델 후보 배치: 20A.

영상 검사·시간 정규화 → 선수 검출·추적·본인 연결 → 포즈 추적·필요한 거리 측정 → 상태 판정 → 행동 판정 → 결과 판정 → 시간 흐름 기반 사건·공방 정리 → 반복 행동/문제/강점·중요 이벤트 분석 → 근거 기반 요약·교정 피드백

- 기술 판정 기본 입력: 단일 프레임 아님, 동작 구간의 키포인트 궤적 변화. 준비·신전/회전·최대 동작·회수·기본 자세 복귀를 해석할 시간 문맥 사용. 구간 경계·필수 단계: 도메인 기준으로 정의
- 접촉 판정 등에서 원본 영상 보조 근거 필요 여부: 실험으로 확인. 포즈만으로 모든 판정 가능하다는 가정 금지

| 산출물 | 필요한 입력 | 입력 불충분 시 |
|---|---|---|
| 근거 재생 | 원본·정상 시간 대응 | 연결 불가 표시 |
| 선수별 관측 | 검출·추적·선수 연결 | 신원 미확정 구간 보류 |
| 자세 관측 | 화면/3D 좌표, 관측 상태 | 해당 관절·측정 결측 |
| 실제 거리 | 기준점·공통 좌표·실제 크기 보정 | 거리 기반 해석 보류 |
| 상태 판정 | 포즈 시계열·거리·선수 방향·02 상태 정의 | 해당 상태만 판단 보류 |
| 행동 판정 | 포즈 시계열·관련 상태·타격/방어/이동 정의 | 해당 행동 분류 불확실 표시 |
| 결과 판정 | 연결된 행동·상태 변화·접촉/방어/거리 근거 | 결과별 독립 보류 |
| 사건·공방 정리 | 시간별 상태·행동·결과, 관계 정의 | 연결 불확실 표시 |
| 명중·반격 | 양 선수 행동·접촉 근거·사건 간 시간 관계 | 시도·명중 구분, 결과 보류 |
| 반복 집계 | 상황 조건·행동·반응·유효 분모 | 유효 사례·판정 불가 건수 병기 |
| 원인·교정 | 관찰 근거·상황·전문가 검증 판단 기준 | 인과 주장 없이 관찰·집계 제공 |
| 경기 요약 | 중요 사건 후보·근거·사건 전후 분석 | 중요 장면의 미판정 여부 표시 |

- 의존 관계 저장: 14의 input_refs
- 상위 입력 정정 시: 관련 결과만 무효화
- 기술 단계 성공 ≠ 사용자에게 유용한 코칭 성공: 별도 검증

관련: 01 — 분석 결과의 정의, 14 — 모듈 간 계약과 공통 데이터

## 입력 부족과 정정의 전파 — 확정
- 실제 거리 부재: 거리 조건의 집계·해석만 차단. 거리 없이 판정 가능한 사건·집계 유지. 실제 거리 요구 철회 아님
- 사건 정정 → 해당 관계/공방 → 관련 집계 → 이를 인용한 주장만 재계산. 입력 불변인 독립 결과 재사용 가능
- 계산 가능한 집계 / 제공 가능한 교정: 별도 판단. 원인·교정 기준 없음 → 관찰 요약까지 생성, 교정 기능 검증은 미완료로 유지
- 구체 계약: 14 기준. 기술 분류 기본 방향: 포즈 시계열(채택). 모델·보조 입력·추가 학습 방법: 미정

분류 상세: 02 — 측정 대상의 정의. 처리 순서 = 논리적 의존 관계. 모든 상태 판정 전까지 모든 행동을 일괄 보류한다는 뜻 아님.
