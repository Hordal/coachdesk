# 34 흐름 분석·피드백 요소 발견 가능성 검증
상태: 합성 사건열 시험 결과(2026-10-17). 실제 영상·팀원 검출 모델 미사용. 코드: `tools/feasibility/flow_findings_sim.py`(표준 라이브러리만 사용).

## 1. 목적과 범위

- 질문: 검출된 동작(사건·상태·접촉 판정)에서 경기 흐름 분석과 피드백 요소(반복 문제·중요 장면) 발견이 02B의 규칙 기반 알고리즘으로 가능한가
- 범위: 유불리 판단 제외. 입력 오류(누락·지터·오분류·판단 불가)가 발견 성능에 주는 영향 측정
- 방식: 패턴을 심은 합성 경기 생성 → 검출 모델 출력처럼 잡음 추가 → R1~R8 규칙 분석 → 심은 패턴과 비교

## 2. 시험 설계

| 항목 | 내용 |
|---|---|
| 합성 경기 | 두 선수 A·B, 한 경기 180초(길이 변화 시험 별도). 거리 상태 사슬, 공격 생성(잽·크로스·훅·킥), 방어·회피·접촉 결과, 반격, 가드 복귀 시간, 밸런스 상태 |
| 심은 패턴 | P1: A의 크로스 뒤 가드 복귀 지연(70%가 0.5초 이상, 평균 0.85초). P2: B가 킥 도달 밖(OUTSIDE)에서 킥을 자주 시도. P3: 큰 밸런스 붕괴 3회(1.5~2.5초) |
| 정답 | 심은 패턴 + 세계에서 발생한 1초 이상 밸런스 붕괴(자연 발생 포함) |
| 관측 모델 | 공격 누락·오검출, 시각 지터, 방어 누락, 접촉 판단 불가·부위 오분류, 거리 상태 오분류, 가드 판단 불가 구간, 밸런스 누락. 잡음 low · mid · high 3단계 |
| 분석 | 02B R1(방어 연결)·R2(결과)·R3(반격)·R4(거리)·R5(가드 복귀)·R7(반복 집계)·R8(중요 장면). 매개변수는 02B 3.1·3.2 시작값(δ_link 200ms, δ_counter 600ms, 가드 늦음 400ms, 큰 붕괴 1.0초, k_min 4, ratio 0.6) |
| 반복 | 조건마다 200경기, 비율은 95% Wilson 구간 |

## 4. 해석

- 가능: 규칙 기반 알고리즘으로 반복 문제와 큰 장면을 되찾을 수 있음. 합성 조건에서 mid 잡음 180초 기준 재현율 0.77~0.83, 360초 이상에서 0.91 이상 + 오발견 0.05 이하
- 중요한 조건
  - 관측 길이: 180초(약 1라운드)에서는 표본 부족으로 재현율·오발견이 모두 나쁨. 360초(2라운드) 이상에서 안정
  - 공격 검출 누락: 30%까지 재현율 0.77, 50% 이상에서 하락
  - 가드 판단 불가 시간: 40%까지 0.71, 60% 이상이면 발견 불가. 입력 품질 요구 기준으로 사용 가능
  - 기준 값: k_min·ratio_min을 높이면 오발견은 줄지만 재현율도 줄어듦(재현율 ≥ 0.8과 오발견 ≤ 0.1을 180초에서 동시에 달성하는 조합 없음)
- 약한 부분: 반격 판정. 시간 규칙(방어 뒤 방어자의 공격)만 쓰면 정밀도 0.31~0.38. 독립적으로 이어진 다음 공격을 반격과 구별하는 조건 필요(30의 D06)
- 불변식 유지: 모든 발견에 분모·판단 불가 횟수·근거 사건이 연결되고 판단 불가를 0으로 바꾸지 않음
- 연산 부담 없음: 경기당 수 ms

## 5. 한계

- 합성 세계는 시험 설계자가 만든 가정. 알고리즘 논리와 오류 전파 시험이지 실제 영상 성능이 아님
- 실제 검출 오류는 독립이 아님(같은 장면에서 연속·집중 발생). 이 시험은 독립 오류를 가정해 낙관적일 수 있음
- 심은 패턴의 강도(70%, 2회 이상 반복)와 02B 시작값은 보정하지 않은 값
- 반격 정답 = 시험에서 생성한 반격만. 현실의 모호한 반격은 포함하지 않음
- 반복 문제 3종(가드 복귀, 거리 실패, 큰 붕괴)만 시험. 후퇴·밸런스 반복 등 나머지 패턴과 문장 생성은 미시험
