## 1. 분석 분류

포즈 시계열 기반 상태 → 행동 → 결과 판정 → 시간 흐름에 따라 사건·패턴 연결. 제품 범위: 01. 데이터 구조·집계·판단 보류 규칙: 14. 아래 = 분석 대상 목록, 모델의 단일 배타 클래스 목록 아님.

### 분류 원칙

- 기술 판정: 기본 자세 → 준비 → 신전·회전 → 최대 동작 → 회수 → 기본 자세 복귀의 시간적 궤적 사용. 필수 단계·경계: 도메인 기준(D05)
- 거리/위치 결과의 분석 기준 예시처럼 행동 자체보다 행동 전후 거리·밸런스 등 상태 변화 분석. 행동 전/후 기준 시점: 카드에 기재
- 스탠스 이름 자체 평가 금지. 가드·밸런스 상태 / 문제 판정: 별개. 피격 없어도 기준 충족 반복 문제 기록 가능
- 필리쉘 = 가드 상태, 숄더롤 = 방어 행동. 피벗 = 이동 행동 하나로 기록, 방어에 쓰였으면 해당 상대 공격과 연결
- 전진·후퇴: 선수 자신의 방향 기준 / 진입·이탈: 상대와의 거리 변화 기준. 조합 표현(전진 + 거리 유지, 후퇴 + 상대 접근) 가능
- 앞손·뒷손: 해당 시각의 스탠스·선수 방향에 연결. 영상 좌우만으로 결정 금지
- '없음' = 관측 근거 판정, 미검출·판단 불가와 구별. '빗나감/회피됨', '거리 확보/회복' 등 중첩·배타성: 도메인 기준
- 클린치 거리 분류 / 클린치 동작 지원: 별개. 니킥 등 적용: 종목·규칙별
- 리치 입력값 / 실제 선수 간 거리 / 기술 도달 범위: 서로 다른 개념. 거리 구간 경계·유불리 기준 임의 작성 금지
