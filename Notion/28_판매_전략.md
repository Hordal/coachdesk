# 28 판매 전략
상태: 판매 순서를 개인 → 체육관 → 완전 상용으로 변경(2026-10-07). 가격 모델은 구독 + 월 분석 횟수 상한 + 초과 시 크레딧이 기본안. 가격 상한·하한은 임시 추정이며 팀 회의에서 결정

판매 순서, 가격 방침, 시장, 채널, 판매 전 준비, 위험. 첫 판매 대상·가격·초기 사용자 조건: 30의 P08~P10.

## 1. 판매 순서

| 단계 | 대상 | 내용 | 전환 조건 |
|---|---|---|---|
| 0. 내부 시험 | 팀 | 팀 촬영 영상으로 1단계 기능 완성(23) | 23의 완료 기준 달성 |
| 1. 체육관 안의 개인 | 체육관에서 훈련하는 개인 수련자 | 개인에게 직접 판매. 무료 또는 할인으로 시작해 사용 반응과 오류 신고를 수집 | 반복 사용, 결과를 실제 복기에 활용하는지 확인, 영상 1건당 처리 비용 실측 |
| 2. 체육관 | 체육관 | 체육관 단위 계약(회원에게 제공). 1단계 사용자가 있는 체육관부터 | 체육관의 유지 의사 |
| 3. 완전 상용 | 체육관 밖 개인, 아마추어 대회·리그 | 일반 판매. 대회·리그는 2단계 결과 판정 추가 후 | 개인 촬영 영상의 분석 품질, 2단계 검증 |

순서 결정 이유(2026-10-07):
- 체육관 단위 영업: 관장·코치 설득 필요. 회원 개인: 직접 영업 용이. 최대 과제 = 첫 사용자 확보
- 체육관 훈련자 대상 → 고정 카메라 촬영, 상대 선수 = 같은 체육관 회원(동의 확보 용이) 유지
- 약점: 개인별 촬영 조건 편차, 상대 선수 동의. 권장 촬영 조건 안내(26)로 완화, 개인 사용자 대상 동의 절차 미정

## 2. 시장

AI 기반 격투기 영상 분석 서비스 다수 출시됨(2026-10 웹 조사).

| 유형 | 사례 | 특징 |
|---|---|---|
| 개인용 영상 분석 앱 | HitSmart, BRAWLER, Punch AI, mmaGPT, Boxing AI: Ring Coach | 섀도복싱·샌드백·스파링 영상의 자세·기술 피드백. 대부분 한 사람의 기술 폼 중심. 월 구독 또는 분석 횟수(크레딧) 과금 |
| 코치·체육관용 플랫폼 | FormMatch, Ringwork(비공개 베타) | 코치 주석·과제 관리, 체육관 단위 운영. 주로 복싱 |
| 경기·대회용 분석 | Jabbr(DeepStrike) | 경기 영상의 타격 수·적중 통계·채점 보조·하이라이트. 체육관·대회 대상 구독형. 시드 투자 500만 달러 유치 |

시장의 빈틈:
- 대부분 한 사람의 기술 폼 분석. 두 선수 공방(내 공격 뒤 상대 반응, 접촉)을 근거 장면과 함께 정리하는 서비스: 드묾
- 분석 결과의 근거·불확실성 노출 서비스: 적음. 판단 불가 장면 별도 표시 서비스: 미확인
- 다수가 복싱 전용, 킥·니킥이 있는 킥복싱·무에타이 지원 약함
- 국내 체육관·한국어 사용자 직접 겨냥 서비스: 미확인

포지셔닝: 스파링이 끝나면 근거 장면과 함께 정리되는 복기 노트

| 차별점 | 제품 근거 |
|---|---|
| 두 선수의 공방 분석 | 두 선수의 행동을 모두 인식하고 내 공격 뒤 상대 공격·접촉을 집계(29) |
| 모든 주장에 근거 장면 | 피드백 문장 → 집계 → 사건 → 원본 시각으로 추적(14) |
| 판단 불가 표시 | 판단 불가·보류를 0회나 실패로 바꾸지 않음(29·31) |
| 4종목 지원 | 복싱·킥복싱·무에타이·MMA. 킥과 다리 접촉 포함. MMA 그라운드는 핵심 사건(테이크다운·상하 관계·탑 컨트롤·서브미션 종료)만 |
| 체육관 환경 지원 | 고정 카메라 촬영 가이드, 선수 지정 |

과장 금지: 1단계 = 접촉 여부·부위까지만 제공, 명중·방어 성공 판정 없음(01). 공식 채점·승패 판정을 판매 문구에 사용 금지.

## 3. 가격

- 경쟁 가격 사례: HitSmart 월 9.99달러·연 89.99달러, 분석 크레딧 5회 7.99달러부터. mmaGPT 월 9~49달러.
- 방침: 경쟁 앱보다 크게 저렴해야 경쟁력 확보
- 임시 추정: 경쟁 가격의 1/3~1/2(월 3~5달러대). 임시 값, 팀 회의에서 결정
- 무료 범위에도 영상 길이·횟수 상한 설정

### 가격 모델(기본안)

개인: 구독 + 월 분석 횟수 상한, 상한 초과 시 크레딧 추가 결제.

| 구성 | 내용 | 값 |
|---|---|---|
| 구독 | 월 구독료에 월 분석 횟수 상한 포함 | 구독료 월 5달러 이하(임시), 미확정 |
| 월 분석 횟수 상한 | 건당 처리 비용 × 상한 횟수 < 구독료 | 미정. 아래 비용 추정: 월 4건(10분 영상) 가정 |
| 크레딧 | 상한 초과 영상을 건 단위로 추가 결제 | 건당 약 0.8달러 이하(임시), 미확정 |
| 무료 범위 | 영상 길이·횟수 상한 | 미정 |

구독 기본 사유:
- 영상마다 결제 시 업로드 망설임 → 사용 반응·오류 신고 감소. 1단계 목적 = 반응 수집
- 개인 수련자: 정기 스파링 → 사용 패턴이 구독과 일치
- 횟수 상한이 월 비용 제한 → 처리 비용 미확인 상태에서도 손실 범위 제한
- 상한 초과 사용자의 비용: 크레딧으로 가격에 반영

진행 순서:
1. 결제 없이 시작. 무료 범위의 길이·횟수 상한만 설정, 사용량·영상 길이 분포 기록
2. 분석 모델 확정 후 영상 1건당 처리 비용 측정(T06)
3. 측정 단가로 월 분석 횟수 상한·구독료 결정

변경 조건: 처리 비용이 예상보다 높거나 사용자별 사용량 차이가 큰 경우 → 크레딧 중심 전환. 체육관 반응이 먼저 나오는 경우 → 체육관 정액 앞당김.

### 상한(임시)

상한 = 경쟁 가격의 1/2 이하.

| 방식 | 경쟁 기준 | 상한(임시) |
|---|---|---|
| 개인 구독 | HitSmart 월 9.99달러 | 월 5달러 |
| 분석 크레딧 | HitSmart 5회 7.99달러(건당 약 1.6달러) | 건당 약 0.8달러 |

### 하한(추정)

하한 = 영상 1건당 처리 비용. 분석 모델 미확정 → 미측정(T06), 아래 = 추정.
- 측정 완료: 영상 준비 단계(10분 영상 약 59초, 59분 50초 영상 약 5분 30초, 디스크 = 원본의 약 1.6배), 선수 검출·추적 시제품(17초 영상에서 검출 초당 6.1프레임, 모델 추론만 초당 29.8프레임, 추적 갱신 프레임당 0.2ms 미만)
- 시제품: 최적화 전, 프레임당 시간의 77% = 전처리
- 포즈·행동·접촉 판정 처리 시간: 가정

10분 영상 1건의 GPU 처리 비용. GPU 단가 가정: RTX 4090급 클라우드 시간당 0.35~0.7달러(2026-06 조사: 0.34~0.69달러).

| 시나리오 | 가정 | GPU 시간 | 비용 |
|---|---|---|---|
| 낙관 | 영상 준비 1분, 검출·추적은 모델 추론 속도(영상 길이의 0.8배, 약 8분), 포즈·판정은 영상 길이의 1배 | 약 19분 | 0.11~0.22달러 |
| 비관 | 영상 준비 1분, 검출·추적은 시제품 처리 속도(영상 길이의 4배, 약 40분), 포즈·판정은 영상 길이의 2배 | 약 61분 | 0.36~0.71달러 |

- 검출·추적 시간: 2026-10-06 실행 기록에서 환산(10분 영상 14,652프레임을 초당 6.1프레임 또는 29.8프레임으로 처리). 오버레이 영상·진단 파일 생성 제외. 추적 = 10분 영상에 약 2초, 무시 가능
- 팀 측정(2026-10-14, RTX 5070 Ti, 영상 6개): 검출기 47~52프레임/초, 검출 루프 약 10.5~11프레임/초, 전체 처리(영상 준비·오버레이 포함) 약 2.4~4프레임/초, 최대 VRAM 183MiB. 위 시제품 값과 환경·범위가 달라 비교하지 않고 별도 기록
- 시제품 프레임당 163ms 중 전처리 126ms → 전처리 감소 시 낙관 쪽 근접 가능. 미시험
- 저장: 영상 1시간당 원본 + 재생용 사본 약 3GB. 7일 보관 약 0.01달러(R2 기준 GB·월 0.015달러, 전송 무료), GPU 비용 대비 소액
- 사용자당 월 4건(10분): 낙관 0.4~0.9달러, 비관 1.4~2.8달러
- 미포함: 서버·DB 고정비, 결제 수수료, 실패·재시도 비용, 인건비
- 두 시나리오 모두 건당 비용이 크레딧 상한(약 0.8달러), 월 5달러 구독의 월 4건 비용 이내. 단 포즈·판정 시간이 가정 → 영상 길이의 몇 배인지에 따라 변동. 검출·추적이 비관 속도일 때 포즈·판정이 영상 길이의 약 3배(GPU 시간당 0.7달러 기준, 0.35달러면 약 10배) 초과 시 건당 비용이 크레딧 상한 초과
- 영상 길이 분포 미확인 → 10분 기준. 1시간 영상 = 6배

| 가격 모델 | 방식 | 대상 | 유의 사항 |
|---|---|---|---|
| 개인 구독 + 크레딧(기본안) | 월 구독에 분석 횟수 상한, 초과분 크레딧 | 1단계·3단계의 개인 | 경쟁 앱 가격과 직접 비교됨 |
| 분석 크레딧만 | 영상(라운드) 단위 결제 | 개인, 체육관의 추가 분석 | 비용·가격 정확 연동, 업로드 전 망설임 |
| 체육관 정액 | 월 분석 영상 수 또는 회원 수 구간별 요금 | 2단계의 체육관 | 1단계 사용량 분포 확인 후 구간 결정. 영상 길이·처리 비용 기준 상한 필요 |

## 4. 판매 채널

- 체육관 안 개인 직접 소개: 같은 체육관 스파링 상대·훈련 파트너 소개, 동의받은 실제 복기 사례
- 코치 추천: 코치가 회원에게 결과를 보여주는 화면 = 홍보 수단 → 결과 화면 공유 용이화. 공유 기본 비활성, 선수 동의 후 허용
- 커뮤니티·콘텐츠: 격투기 커뮤니티·영상 채널에 복기 사례 공개. 해당 선수 동의 장면만 사용

## 6. 위험과 대응

| 위험 | 대응 |
|---|---|
| 경쟁 앱의 개인 시장 선점 | 두 선수의 공방 분석·근거 장면·국내 체육관 환경으로 차별화, 가격을 크게 낮춤 |
| 투자를 유치한 경쟁사(Jabbr 등)의 체육관 진출 | 국내 체육관·한국어·4종목·이미 쓰는 개인 사용자 기반으로 방어 |
