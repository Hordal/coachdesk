# 19 결과의 오해 방지
상태: 표시 기본안

## 화면 규칙
| 상황 | 표시 |
|---|---|
| 값 추정 성공 | 단위·측정 정의·근거 시각 병기 |
| 일부 분석 가능 | 전체 시간 + 유효 시간·제외 구간 병기 |
| 관측 없음 | 발생 0회 아님, 확인 불가 |
| 값 결측 | 그래프 간격 표시, 0 연결 금지 |
| 보간·모델 추정 | 실제 관측과 선 스타일·문구로 구별 |
| 불확실성 미검증 | 백분율 정확도·가짜 오차범위 표시 금지 |
| 원본 삭제 | 근거 영상 만료, 재생·재계산 불가 표시 |

- 별도 영역 표시: 관찰 사실 / 모델 해석 / 사용자 맥락
- 핵심 피드백 개수 최소값 없음
- 숫자 자릿수: 검증된 정밀도 기준, 내부 소수점 자릿수 그대로 노출 금지

## 검증
- 사용자의 구별 확인: 값 없음 / 0 / 추정 / 실측 기준 보정
- 색만으로 상태 구별 금지, 텍스트·아이콘 병행
- 사용자 표시 문구: 구조화된 상태로 생성

## 집계와 피드백 출력 — 확정

- 기본 관찰·집계 문장: 구조화된 값 + 템플릿. 개수·비율·시각은 출력 전 원자료와 대조. 언어 모델 필수 아님, 도입 시에도 같은 검사
- 함께 표시: '확인된 공격 전체 → 후속 판정 가능 → 해당 결과 발생 → 미판정/제외' 수. 조건부 비율: 분모로 쓴 사례 명시, 분모 0 → 비율 없음 표시
- 분리: 관찰·집계 / 원인 가설 / 교정 방향. 원인·교정 근거 부족 → 해당 부분만 보류, 유효 관찰 유지. 발생 순서만으로 '때문에' 인과 표현 생성 금지
- 각 주장: 근거 장면 연결. 원본 만료 시 시각·구조화 근거 유지, 영상 검증 불가 표시. 보관 정책 변경·근거 클립 자동 장기 보존 금지
- 관찰 요약만 제공 시 '교정 방향 미제공' 명시, 완성된 교정 피드백으로 집계 금지. 발견·강점 최소 개수 없음

정보 표현 계약. 화면 배치·모델 선택·전문가 교정 기준: 별도 작업.
