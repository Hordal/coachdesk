# 화면 예시

웹앱의 실제 화면을 촬영하고 각 화면의 기능을 번호로 설명한 이미지다. 모두 개발 모드에서 실제 서버와 실제 스파링 영상(공개 영상과 파이프라인 시험 영상)으로 촬영했다. 결과 화면의 사건·판정은 설명용 가상 예제를 사람이 입력한 것으로 가져온 것이며 실제 분석 결과가 아니다.

## 설명 이미지(`설명/`)

| 파일 | 내용 |
|---|---|
| 00_화면_흐름도 | 영상 올리기부터 정정·삭제까지 화면 흐름 8단계 |
| 01_영상목록 | 올린 영상, 분석 실행(가상 예제, 수동 입력, 분석 전) |
| 02_영상올리기_선택 | 파일·종목 선택 |
| 03_영상올리기_진행 | 조각 업로드 진행률, 취소 |
| 04_영상준비 | 처리 단계, 규격 안내, 삭제 영역 |
| 05_검출추적_가져오기 | 파이프라인 출력 가져오기, 후보 트랙 진단 |
| 06_선수지정 | 후보 프레임의 트랙 상자, 나·상대 선택과 확정 |
| 07_사건판정_가져오기_오류 | 검증 실패 시 오류 목록 |
| 08_결과요약 | 집계 문장, 근거 구간, 보류된 주장 |
| 09_집계상세 | 분자·분모·판단 불가·제외 |
| 10_사건상세 | 사건의 판정, 관계, 근거 |
| 11_장면복기 | 실제 영상, 프레임 이동, 타임라인, 판정 |
| 12_장면복기_관절 | 관절 오버레이(가상 예제) |
| 13_정정기록 | 본인 지정 정정, 이력, 오류 신고, 의도 설명 |
| 14_삭제_확인 | 삭제 확인 단계 |
| 15_휴대폰_화면 | 휴대폰 너비 화면 |
| 16_로그인 | 로그인 모드의 로그인 화면 |
| 17_계정관리 | 관리자의 초대 만들기와 계정 목록 |
| 18_초대수락 | 초대 수락과 이용 동의 |

## 다시 만들기

개발 서버(API 8000, 화면 5173, 워커)를 `AUTH_MODE=dev`와 빈 `DATA_DIR`로 띄운 뒤 `tools/screenshots`의 스크립트를 순서대로 실행한다. 설치는 `pip install playwright pillow httpx`이며 브라우저는 설치된 Chrome을 쓴다.

| 스크립트 | 하는 일 |
|---|---|
| `capture.py` | 시험 영상을 올리고 화면을 조작하며 스크린샷을 `원본/`에 저장 |
| `annotate.py` | 요소 위치를 읽어 번호와 설명을 붙인 이미지를 `설명/`에 저장 |
| `extras.py` | 화면 흐름도와 휴대폰 화면 모음 |
| `capture_auth.py` | `AUTH_MODE=session`의 빈 `DATA_DIR`에서 로그인·관리자·초대 수락 화면 |
| `notion_package.py` | 노션 가져오기용 ZIP(`Notion_업로드.zip`)을 만든다. README 내용과 설명 이미지가 들어 있다 |
