# 20A 모델 후보와 검증 계획
상태: 후보 검토 중. 최종 모델·학습 방식·실제 성능은 미확정.

## 팀 연구 검증 결과(2026-10-14)

팀 연구 묶음의 검증 보고서 기준. 내부 평가·개인 로컬 연구 범위이며 제품 통합·상업 이용 승인이 아님. 주석이 없어 정확도(precision·recall·mAP·ID switch 비율)는 산출하지 않음.

| 후보 | 실행 범위 | 결과 | 상태 |
|---|---|---|---|
| RT-DETR R18 + ByteTrack | 6개 영상 전체 프레임(내부 평가 전용) | 가까운 스파링은 겹침 뒤에도 두 ID 유지. 원거리 가림: 완전 가림 뒤 ID 교체. 관중 4K: 선수가 3개 이상 ID로 분할, 레프리·관중이 긴 트랙 생성. 검출기 47~52프레임/초, 검출 루프 약 10.5~11프레임/초 | 기준 01 통과, 02 이슈, 03 BLOCKED |
| MediaPipe Pose Landmarker full | 클립 01·02·04 일부 구간, CPU/XNNPACK, 1프레임 약 13~22ms | 라이선스 개인 로컬 연구 SUPPORTED(Apache-2.0, 모델 카드 이슈 댓글). 33점 반환, GPU delegate 불가. `num_poses=2`가 두 선수 분리를 보장하지 않음(겹치면 1개로 합쳐지거나 한쪽에 몰림). 손목 visibility 낮음. VIDEO 모드는 IMAGE보다 낫지 않음 | PASS WITH ISSUES, 제품 통합 승인 없음 |
| RTMPose-s(COCO) | 실행 안 함 | 체크포인트 파일 단위 라이선스·AI Challenger 계보 UNRESOLVED | BLOCKED |
| YOLO26n·n-seg·s-seg | 6개 영상 전체 프레임, 격리 실행 | AGPL-3.0, 제품 통합 승인 안 됨(P07 유지). 가림·원거리에서 사람 누락·융합. 분할 모델이 일부 장면에서 개선, 전체 일관 개선 아님. 자동 의사 라벨 160프레임 중 152프레임이 사람 검토 대기 | 연구 한정 |

- 팀 포즈 연구의 선수 신원: 전부 `UNRESOLVED`, `candidate:N`은 클립 내 저장 트랙 ID이며 선수·클립 간 동일 인물이 아님
- 포즈 품질 판정 임계값(손목 visibility 0.5, 신장 0.35 등)은 연구용 휴리스틱


## 촬영·출력 조건

- 2D 위치 / 3D 관절각 / 기술명: 서로 다른 출력. 글러브 끝 ≠ 손목·장갑 속 손가락(측정점 다름)
- 결정 필요: 신체 경계가 보이는 2D 윤곽 vs 가려진 표면까지 포함한 3D 복원. 모든 카메라에서 안 보이는 부분 = 추정
- 잽 발생 감지·궤적·접촉 순간: 별도 평가. 영향 요인: 촬영 fps, 노출, 블러, 선수 화면 크기, 압축. 저fps 실제 촬영 ≠ 고fps 영상 다운샘플
- 다중 시점 필요 조건: 동시 촬영, 동기화/drift 관리, 카메라 내부/외부 보정, 크기 기준, 시점 간 선수 대응. 이동 카메라: 시간별 보정 필요
- 코드 / 가중치·데이터 라이선스: 별도 확인. 선택 기준에 예산·다운로드 접근 조건·장비·학습 가능성 포함

상업용 기본 조합(제안)
- 검출: 상업 이용 확정 후보 없음(RT-DETR R18: 내부 평가 전용, RTMDet 체크포인트: 차단, RF-DETR: 학습 데이터 조건 확인 필요)
- 추적: ByteTrack(원본)
- 포즈: RTMPose(COCO 전용 가중치) vs MediaPipe(발 점) 비교
- 기술 인식: LSTM·Transformer Encoder 직접 학습
- 접촉 판정: V-JEPA 2 또는 VideoMAE V2
- YOLO·Ultralytics 계열: 사용 안 함(P07)

격투기 전용 사전학습 가중치(포즈·행동·접촉): 상업 이용 가능한 공개 가중치 못 찾음(2026-10-07 조사). 기본 방식: 범용 가중치 + 팀 자료로 직접 학습.

검출 모델의 학습 데이터
- RF-DETR Nano~Large: 코드·COCO 사전학습 가중치 모두 Apache 2.0. COCO 주석 CC BY 4.0이나 이미지는 Flickr 이용 약관 적용 → 상업 위험 항목
- 대안 Open Images: 주석 CC BY 4.0, 이미지 CC BY 2.0 수집, Google의 개별 이미지 라이선스 보증 없음. 사람 클래스 직접 미세조정안: 법률 검토 필요, 미시험(P07)
