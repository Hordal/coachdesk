# 24 기술 인식과 접촉 판정 방법
상태: 1단계 방법 후보·검증 계획. 구현·성능 미검증. 도메인 기준 없이 시작 가능한 범위 우선.

## 1. 1단계 범위

| 산출 | 내용 | 기록 형식(14) |
|---|---|---|
| 기술 인식 | 선수, 기술명(‘분석 항목 및 판정 구조’의 타격·방어·이동 세부 분류), 시작·끝, 최대 동작 시점 | Event(event_label, 시작·끝), phase_marks |
| 접촉 여부 | 공격 행동마다 있음·없음·판단 불가, 접촉 시각 | Assessment(question_code=contact_occurred), 접촉 시 Event(event_label에 CONTACT 포함) |
| 접촉 부위 | 머리·몸통·다리·가드(팔·글러브)·불명확 | Assessment의 contact_region |
| 시간적 후속 공격 | 한 선수의 공격 뒤 정해진 시간 창 안의 상대 공격 | EventRelation(relation=followed_by). 반격(counter_to) 판정은 D06·D07 기준이 생긴 뒤 |

- 명중·빗나감·방어됨·회피됨·방어 성공: 2단계에서 같은 사건에 Assessment 추가
- 1단계 결과만으로 방어 성공·회피 주장 금지

## 2. 임시 운영 정의

도메인 기준(D05·D06) 확정 전, 라벨·평가 시작용 팀 내부 정의. 모든 라벨·결과에 정의 버전(`team-provisional-v0` 등) 기록. 도메인 기준 확정 시 버전 상승 → 영향받는 라벨만 재검토.

| 항목 | 임시 운영 정의 |
|---|---|
| 기술 1회 | 공격 부위가 기본 자세 위치에서 출발해 최대 신전·회전에 도달한 뒤 회수되는 한 번의 궤적. 중간에 멈추고 다시 뻗으면 2회 |
| 시작·끝 | 공격 부위가 기본 자세 위치를 벗어나기 시작한 프레임 ~ 회수되어 기본 자세 위치에 돌아온 프레임. 돌아오기 전 다음 기술이 시작되면 그 시작 프레임 |
| 최대 동작 시점 | 공격 부위가 몸 중심에서 가장 멀어진 프레임 |
| 앞손/뒷손 | 해당 시각 스탠스 기준. 영상 좌우로 정하지 않음 |
| 접촉 | 공격 부위(글러브·발·정강이·무릎)가 상대의 신체 또는 가드에 닿는 것이 영상에서 확인되는 경우 |
| 접촉 없음 | 공격 부위와 상대 사이에 간격이 보이거나, 최대 동작 전후 내내 닿지 않았음이 확인되는 경우 |
| 판단 불가 | 접촉 순간 공격 부위나 목표 부위가 가려졌거나, 겹쳐 보이지만 닿았는지 확인할 단서가 없는 경우 |
| 판단 불가(기술) | 기술 종류를 구별할 수 없으면 ‘판단 불가 타격’으로 기록하고 시도는 유지 |

## 3. 기술 인식

### 입력 정규화

- 선수별 포즈 시계열 → 공통 키포인트 형식 변환(14)
- 원점: 골반 중심. 크기: 몸통 길이(어깨 중심–골반 중심)로 나눔. 화면 크기·거리 차이 완화용, 실제 거리 아님
- x축: 해당 선수 골반 → 상대 골반 방향. 같은 기술이 화면 좌우와 무관하게 비슷한 궤적
- 왼손/오른손 → 스탠스에 따라 앞손/뒷손으로 변환. 좌우 반전으로 학습 자료 증강 시 오소독스↔사우스포가 바뀌어도 앞손/뒷손 기준 라벨(잽·크로스 등) 유지
- 결측 관절: 0 대체 금지, 결측 표시 채널 사용

### 후보 구간 찾기

| 방법 | 내용 | 비고 |
|---|---|---|
| 속도 피크 | 손목·발목·무릎의 정규화 속도가 피크를 이루는 구간을 공격 후보로 | 학습 없이 시작 가능. 라벨링 보조로도 사용 |
| 슬라이딩 윈도우 | 일정 길이 창을 겹쳐 분류 후 인접 창을 병합 | 창 길이는 기술 길이 분포로 결정 |
| 프레임별 분류 + 병합 | 프레임마다 ‘기술 진행 중’ 라벨을 예측해 연속 구간으로 묶음 | 시작·끝 정밀도에 유리 |

### 분류

| 단계 | 방법 | 비고 |
|---|---|---|
| 기준선 | 손으로 만든 특징(최대 신전 거리, 팔꿈치 각도 변화, 궤적 방향·높이, 회전 여부, 사용 부위) + 간단한 분류기 | 자료가 적을 때도 동작. 오류 해석이 쉬움 |
| 학습형 | LSTM(기준), Transformer Encoder(비교) — 기본 모델 후보 | 정규화 시계열 입력. 자료가 늘어나면 기준선과 비교 |
| 계층 분류 | 먼저 펀치/킥/니킥/비타격, 다음 세부 기술 | 세부 분류 자료가 적은 기술의 혼동을 줄임 |
| 판단 불가 | 분류 점수가 개발 검증 자료로 정한 기준보다 낮으면 기술명만 보류 | 점수를 정확도 확률로 표시하지 않음 |

- 공개 데이터셋 BoxingVI(4-2절): 상업 이용 조건 없음 → 제품용 학습 사용 금지. 클립 분할·라벨 방식만 참고, 기술 분류기는 팀 자료로 학습·평가
- 포즈 기반 대안 PoseC3D(4-1절): LSTM·Transformer Encoder와 같은 자료로 비교
- 방어(블록·패리·슬립·덕킹·스웨이백·숄더롤)·이동: 상대 공격 사건과의 시간 관계 필요 → 공격 인식 이후 단계. 1단계: 공격 기술 인식 우선 검증

### 평가

- 사건 단위 일대일 매칭: 같은 선수 + 시간 구간이 겹치는 정답 사건·예측 사건 짝짓기(18)
- 보고: 기술별 누락·오탐·혼동(특히 잽/크로스, 훅/어퍼컷, 앞손/뒷손), 시작·끝·최대 동작 시점 프레임 오차, 판단 불가 비율
- 촬영 각도·프레임률·선수 화면 크기별 구분 보고

## 4. 접촉 판정

### 방법 후보

| 후보 | 방법 | 장점 | 한계 |
|---|---|---|---|
| A. 포즈 기하 규칙 | 최대 동작 시점 전후 짧은 창에서 ① 공격 부위 끝점(손목·발목에 글러브·발 크기 보정)과 상대 신체 영역(머리 원, 몸통 다각형, 다리·팔 선분)의 화면 거리, ② 공격 부위의 급감속, ③ 목표 부위의 순간 이동·속도 변화를 결합 | 학습 자료 없이 시작. 근거 설명이 쉬움. 라벨링 보조로 활용 | 카메라 1대에서 화면상 겹침과 실제 접촉을 구별 못 함. 글러브 크기·가림에 약함 |
| B. 영상 클립 분류 | 최대 동작 시점 주변의 두 선수 영역을 잘라 짧은 클립으로 {접촉-머리, 접촉-몸통, 접촉-다리, 접촉-가드, 접촉 없음, 판단 불가} 분류. 사전학습 영상 모델을 미세조정하거나 고정한 채 작은 분류기만 학습. 모델 후보는 4-1절 | 포즈에 없는 글러브·반동·흔들림 정보 활용 | 라벨 자료 필요 |
| C. A+B 결합 | 포즈 특징과 클립 특징을 함께 사용. 두 근거가 어긋나면 판단 불가 | 오탐 억제 | 구현 복잡도 |
| D. 영역 분할 | SAM 계열로 공격 부위·상대 신체 마스크를 만들고 경계 접촉·겹침 확인 | 글러브 실제 크기 반영 | 화면 겹침 문제는 A와 같음. 계산량 큼 |

### 기본 진행 순서

1. A를 기준선으로 구현. 화면상 겹침만 있고 감속·목표 이동 단서 없음 → '접촉' 아닌 '판단 불가'. 근접 겹침의 접촉 단정 금지 우선
2. A의 결과를 라벨링 도구 초기값으로 사용 → 라벨 작업 속도 향상. 라벨러가 확인·수정한 것만 정답으로 사용
3. 라벨 축적 후 B 학습 → A와 비교, 차이 크면 C 시험. B 학습 자료: 팀 촬영·동의받은 사용자 영상(공개 데이터셋: 상업 이용 불가, 4-2절)
4. D: 겹침·경계 문제가 주된 오류로 확인될 때만 검토

### 접촉 부위

- 접촉 시각의 공격 부위 끝점과 가장 가까운 상대 신체 영역으로 결정. 팔·글러브 영역이 머리 앞을 가림 → '가드'
- 영역 간 거리 차이 작음·영역 가림 → '불명확'

### 평가

- 공격 사건별 접촉 여부 정밀도·재현율, 판단 불가 비율: 별도 보고. 겹침을 접촉으로 판정한 오탐: 별도 항목 집계
- 접촉 부위 혼동행렬(머리/몸통/다리/가드/불명확)
- 측면 촬영 / 정면·대각선 촬영 구분 보고. 같은 공방의 다각도 자료 있으면 단일 시점 판정과 비교해 시점 한계 정량화

## 5. 시간적 후속 공격

- 반격 관계(counter_to): 도메인 기준 필요 → 1단계 판정 안 함
- 대신 한 선수의 공격 종료 후 정해진 시간 창 안에 시작된 상대 공격을 `followed_by` 관계로 기록
- `followed_by` = 시간 순서만 의미, 피드백 문장에서 '반격' 표현 금지
- 시간 창: 처리용 설정값, 도메인 기준 아님

## 6. 그 밖의 판정 방법 후보

- 검증된 방법 없음 → 후보만 나열. 구현·시험 전, 추천·우선순위 없음
- 비교: 같은 라벨 세트로 Precision·Recall·F1, 시작·끝 시각 오차, 판단 불가 비율, 중요 사건 누락률(18). 촬영 각도·프레임률·선수 화면 크기별 구분
- 라이선스: 20A 기준(상업 이용 가능한 것만)으로 선별

### 거리(D01, T02)

| 후보 | 방식 | 한계 |
|---|---|---|
| 정규화 거리 | 두 선수 기준점 사이 거리를 몸통 길이 단위로 계산 | 카메라 각도와 원근의 영향 |
| 바닥 표식 보정 | 바닥의 알려진 점으로 화면 좌표를 실제 평면 좌표(미터)로 변환 | 촬영 때 표식이 필요 |
| 키 기반 척도 | 입력한 선수 키로 픽셀당 길이를 추정 | 자세·원근 오차가 큼 |
| 접촉 장면 보정 | 실제 접촉이 일어난 순간의 거리 분포로 구간 경계를 정함 | 접촉 라벨이 먼저 필요 |

| 후보 | 방식 |
