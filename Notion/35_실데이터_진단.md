# 35 실데이터 진단 (라벨 없이)

팀 동작 검출 모델 실제 출력(연구 묶음 2026-10-17)에 상태 판정·후보 정책을 적용한 결과. 정확도 검사 아님.
도구: `tools/diagnostics/flow_diagnostics.py`. 테스트: `backend/tests/test_diagnostics.py`

## 1. 입력 커버리지

| 항목 | 값 |
|---|---|
| 사건 | 1건(`PUNCH_CANDIDATE`, 후보). 확인 사건 0건 → 판정·집계·주장 0건 |
| 1C 클립 01 | 211줄 중 `candidate:N` 있음 60줄, 손 판정 가능 67손 중 높이·턱 기준 충족 58 |
| 1C 클립 02 | 88줄 전부 `candidate:N` 없음 → 상태 0 |
| 1C 클립 04 | 89줄 중 44줄 `candidate:N` 있음, 손 판정 가능 13 / 88손(나머지 `missing_input`) |
| 1B 클립 01 | 108줄 중 48줄 `candidate:N` 없음, 상태 구간 4개 |
| 판단 불가 시간 | 클립 01(1C)에서 상태 1.13초 대 판단 불가 1.21초(`missing_input`·`too_short`) |
| `low_guard` | 모든 입력에서 0건 |

- 전체 프레임 줄(`full_frame`)은 `candidate:N`이 없어 사용 불가
- 막히는 입력: 확인 사건, 방어·회피 사건, 접촉, 거리 상태, 밸런스 상태, 상대 방향·앞발(뒷손 매핑)

## 4. 시간 측정 정확도 (정답 주입)

도구: `tools/diagnostics/timing_injection.py`. 방법: 실제 포즈 한 장을 기준 자세로 복제해 '가드가 정확히 d ms 늦게 복귀'하는 줄을 만들고, 상태 판정 + 가드 복귀 판정이 d를 복원하는지 측정(조건당 20회, 지연 100~1200ms).
- 프레임 간격 41.7ms, 손목 잡음 σ = 0.046 몸통(실제 연속 프레임 변화에서 추정, 실제 움직임이 섞여 있어 상한)
- 검출 모델 오류는 측정 대상 아님. 상태 판정·시간 측정 층만 측정

| 조건 | 판단 불가 | 지연 오차 중앙값 | 지연 오차 최대 | 늦음/정상 구분 정답률 |
|---|---|---|---|---|
| 잡음 없음 | 0% | 12~27ms | 41ms(1프레임 이내) | 100% |
| 실측 잡음 | 0% | 12~28ms | 242ms | 95~100% |
| 실측 잡음 ×3 | 20~45% | 130~361ms | 1065ms | 15~75% |
| 프레임 10% 누락 | 0% | 18~27ms | 242ms | 90~100% |
| 프레임 30% 누락 | 0% | 18~37ms | 255ms | 85~100% |

- 아래 표는 히스테리시스 도입 전. 도입 후 결과는 4-1절
- 잡음 없음: 오차가 프레임 간격 이내 → 판정 로직 자체의 시간 오차는 1프레임
- 실측 잡음: 중앙값은 유지되나 드물게 200ms 이상 오차 → 임계값 근처에서 상태가 쪼개지는 깜빡임 때문. 히스테리시스 미구현이 원인 후보
- 잡음 ×3: 판단 불가와 오판이 급증 → 포즈 품질이 나쁜 영상에서 지연 판정 신뢰 불가
- 기준(400ms) 근처 지연(300·350ms): 프레임 누락 30%에서 정답률 85~90%로 하락 → 경계 근처 결과는 '늦음/정상' 단정 대신 지연값 병기 필요

### 4-1. 히스테리시스 도입 효과

여유 0.09 몸통 길이(손목 잡음 σ 0.046의 2배). 현재 하이·로우가드 상태를 완화한 조건에서도 유지, 판단 불가·관측 간격 초과·손 교체 시 이어받지 않음.

| 조건 | 항목 | 도입 전 | 도입 후 |
|---|---|---|---|
| 실측 잡음 | 지연 오차 최대 | 242ms | 41ms |
| 실측 잡음 | 늦음/정상 정답률 | 95~100% | 100% |
| 실측 잡음 ×3 | 판단 불가 | 20~45% | 0~15% |
| 실측 잡음 ×3 | 지연 오차 중앙값 | 130~361ms | 30~89ms |
| 실측 잡음 ×3 | 지연 오차 최대 | 270~1065ms | 249~824ms |
| 프레임 누락 10%·30% | 오차·정답률 | 변화 없음 | 변화 없음(누락은 히스테리시스로 해결 불가) |
| 실데이터 1C 클립 01 | 상태 구간 / 판단 불가 구간 | 3 / 8 | 3 / 4 |
| 실데이터 1C 클립 01 | too_short 시간 | 0.25초 | 0 |

- 비용 측정은 4-2절
- 주입 시험(위 표)은 계단 형태 이동이라 전환 지연 비용을 보여 주지 못함
- 잡음 ×3의 큰 오차(최대 800ms 수준): 남아 있음 → 포즈 품질이 나쁜 영상은 여전히 신뢰 불가
- 여유 값은 잡음 상한 기반 임시값. 포즈 연동 후 재산출

### 4-2. 전환 지연 (일정 속도 이동)

방법: 손이 일정 속도(몸통 길이/초)로 내려갔다 올라올 때 네 전환 시각의 오차(추정 − 정답)를 측정. 정답: 잡음 없는 궤적에서 엄격한 기준으로 1ms 단위 계산. 조건당 20회, 오차는 중앙값(ms). 프레임 간격 41.7ms.

잡음 없음, 히스테리시스 도입 후:

| 속도(몸통/초) | 하이가드 종료 | 로우가드 시작 | 로우가드 종료 | 하이가드 복귀 시작 |
|---|---|---|---|---|
| 0.5 | +203 | +26 | +197 | +23 |
| 1 | +110 | +17 | +113 | +21 |
| 2 | +56 | +22 | +64 | +29 |
| 4 | +44 | +20 | +44 | +24 |
| 8 | +35 | +28 | +22 | +21 |

- 도입 전: 모든 전환이 +15~33ms(샘플링 간격 이내)
- 지연은 상태에서 나갈 때만 발생(하이가드 종료·로우가드 종료). 상태에 들어갈 때(로우가드 시작·하이가드 복귀 시작)는 변화 없음 → 가드 복귀 지연(R5)의 복귀 시각은 영향 없음
- 크기: ≈ 0.09 ÷ 속도 + 샘플링 간격. 느린 손(0.5몸통/초)은 약 0.2초 늦게 종료로 기록, 빠른 손(4몸통/초 이상)은 40ms 이하
- 영향받는 곳: 상태 종료 시각을 쓰는 계산(상태 지속 시간, 다음 상태 시작 시각 기준 판정)
- 실측 잡음에서 도입 전 로우가드 종료 오차 중앙값 −95~−383ms(속도 0.5·1·2·4): 잡음 때문에 상태가 일찍 끊김. 도입 후 +24~149ms로 방향이 반대(늦게 끊김)이고 크기가 줄어듦

## 5. 판단

- 규칙 로직: 합성·실입력 모두에서 원칙 위반 없음
- 분석 불가 원인은 규칙이 아니라 입력: 확인 사건·방어·접촉·거리·밸런스 부재, `candidate:N` 없는 줄 다수
- 팀 요청 후보: 확인 가능한 사건 라벨, 방어 사건, 전 프레임 `candidate:N` 부여, 앞발·상대 방향 정보
