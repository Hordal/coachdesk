# 29 분석 구조의 구현 요구
상태: 구현 기본안. 분류 항목 자체는 ‘분석 항목 및 판정 구조’를 따른다.

분석 항목 및 판정 구조의 분류·처리 흐름·시나리오 구현에 필요한 관측·측정·기록 규칙.

## 1. 처리 흐름과 구현 단계

| 흐름 단계 | 구현에 추가로 필요한 것 | 산출물 |
|---|---|---|
| (선행) | 영상 형식·시간·회전 확인, 두 선수 검출·추적, 사용자/상대 지정 | 선수별 추적 구간 |
| 포즈 추적 | 키포인트 정의·좌표계 통일, 결측·가림 표시, 실제 크기 보정(거리용) | 선수별 관절 시계열, 측정값 |
| 상태 판정 | 관찰 Feature 계산, 상태 기준(30의 D01~D04) | 상태 구간: 거리·가드·스탠스·밸런스 |
| 행동 판정 | 기술 판정 6단계의 구간 인식, 두 선수 모두 분류 | 행동 사건: 타격·방어·이동 |
| 결과 판정 | 1단계: 접촉 여부·접촉 부위. 2단계: 명중·방어·회피 등 결과, 거리 변화, 행동 전후 상태 비교 | 행동별 접촉 판정(1단계), 결과 판정(2단계) |
| 사건 정리 | 공격–반응–후속 행동 연결, 처리 구간 경계 병합 | 공방. 1단계는 시간적 후속 공격, 반격·카운터 판정은 D06 이후 |
| 그라운드 사건(MMA) | 스탠딩·그라운드·전환 상태 구간, Takedown 시도와 결과, Ground Relation, Top Control 후보와 확정, Submission 후보와 종료. 최소 유지시간·병합 간격은 버전된 설정값(33) | 그라운드 사건: TAKEDOWN, GROUND_RELATION, TOP_CONTROL, SUBMISSION_FINISH |
| 반복 패턴 | 같은 상황 묶기, 분모·판단 불가 관리 | 반복 행동·문제·강점, 중요 단발 이벤트 |
| 사용자 피드백 | 시나리오 문장 템플릿, 근거 장면 연결, 보류 처리 | 관찰·집계·원인·교정 문장 |

처리 순서, 입력 부족 시 처리, 정정 전파: 10.

## 2. 분석 단위 — 행동 전후의 상태 변화

- 분석 대상: '크로스를 했다'는 사실보다 공격 전 상태 → 행동 → 공격 후 상태의 변화(예: 공격 전 거리 = 펀치 거리, 공격 후 거리 = 근거리, 공격 후 밸런스 = 불안정)
- 행동 사건의 전·후 상태 구간 참조 구조: 14의 6절
- '공격 후 가드 복귀'·'밸런스 유지'·'후속 공격 연결'의 결과 분류 정식 항목 추가 여부: 30의 D07. 행동 전·후 기준 시점: D05

## 3. 관찰 Feature별 필요한 신체 점·측정

가드·스탠스·밸런스 Feature의 계산 정의·필요 관절: 25의 3절. 아래 = 25에 없는 관측 요구, 25와 함께 포즈 모델 선택(20A)·촬영 조건(26)의 요구사항.

| 분류 | 관찰 Feature | 필요한 신체 점·측정 | 구현상 주의 |
|---|---|---|---|
| 거리 상태 | 사거리 밖~클린치 거리 | 두 선수 기준점 간 실제 거리, 선수 신체 정보 | 화면 픽셀 거리로 대신하지 않음. 측정점·구간 경계는 D01 |
| 타격 기술 | 기본 자세 → 준비 → 신전/회전 → 최대 동작 → 회수 → 복귀 | 손목·팔꿈치·어깨(펀치), 발목·무릎·골반(킥)의 궤적 | 빠른 동작은 프레임률·블러 영향이 큼. 평활화가 최대 동작을 지우는지 검사 |
| 방어 | 블록·패리·상체 회피·이동 회피 | 상대 공격 사건과의 시간 관계, 머리·상체 이동, 손 위치 | 상대 공격도 분류해야 방어로 해석 가능 |
| 이동 | 전진/후퇴, 진입/이탈 | 선수 자신의 방향 기준 이동, 상대와의 거리 변화 | 두 속성을 독립 기록(전진+거리 유지, 후퇴+진입 가능) |
| 접촉(1단계) | 접촉 여부, 접촉 부위(머리·몸통·다리·가드·불명확) | 최대 동작 전후의 공격 부위(손목·발목)와 상대 머리·몸통·다리·팔 위치, 공격 부위 감속, 맞은 쪽 머리·몸통의 순간 이동 | 카메라 1대에서는 화면상 겹침과 실제 접촉을 구별하지 못할 수 있음. 방법 후보는 24(T03) |
| 타격·방어 결과(2단계) | 명중·방어됨·회피됨·빗나감 | 접촉 판정, 방어 행동, 결과 기준(D07) | 1단계 접촉 판정 위에 추가 |

- 발 방향: 뒤꿈치·발끝 점 필요. 핵심 관절 13점에는 발 점 없음 → 발 점 제공 모델(MediaPipe Pose Landmarker 등) 필요, 없으면 스탠스 판정 보류
- 글러브 끝 ≠ 손목 점

## 4. 시나리오별 필요한 판정

예상 분석 시나리오의 피드백 출력 조건: 아래 판정 전부 유효. '1단계 판정' 열 = 결과 판정을 접촉 여부·부위로 대체한 형태. 이 표: 첫 실제 영상 검증의 사례 목록(31)으로도 사용.

| 시나리오 | 필요한 판정(2단계 기준) | 1단계 판정 | 선행 조건 | 일부 보류 시 제공 내용 |
|---|---|---|---|---|
| 1. 적절한 거리 공격 성공 | 거리·가드·밸런스 상태, 잽, 명중, 공격 후 가드 복귀·밸런스 유지 | 명중 → 머리·몸통 접촉 | 실제 거리, 접촉 판정, 가드 복귀 기준 | 거리 불가 시 ‘적절한 거리’ 표현 제외 |
| 2. 사거리 밖 공격 | 사거리 밖, 크로스, 빗나감, 공격 후 상체 이동·밸런스 | 빗나감 → 접촉 없음 | 실제 거리와 기술 도달 범위의 관계 기준 | 거리 불가 시 접촉 없음·밸런스 변화만 |
| 3. 하이가드 방어 | 가드·밸런스·거리 상태, 상대 크로스, 사용자 블록, 방어됨, 방어 후 밸런스 | 방어됨 → 가드 접촉 | 상대 행동 분류, 접촉 부위 구분(P03) | 접촉 불명확 시 블록 동작만 |
| 4. 회피 후 카운터 | 상대 잽, 슬립, 회피됨, 후속 크로스, 명중, 연결 성공 | 회피됨 → 상대 공격 접촉 없음, 명중 → 접촉 | 후속 공격 연결 기준(D06) | 후속 접촉 불명확 시 슬립 동작과 후속 공격 시도만 |
| 5. 후퇴 중 밸런스 불안정 | 초기·최종 거리, 상대 진입, 사용자 후퇴, 거리 확보, 밸런스 변화·회복 | 2단계 기준과 같음 | 거리 변화, 밸런스 단계 기준(D04) | 거리 불가 시 후퇴와 밸런스 변화만 |
| 6. 반복 가드 복귀 실패 | 크로스 횟수, 회차별 공격 후 가드 복귀 지연 | 2단계 기준과 같음 | 복귀 지연 기준(D02·D07), 반복 최소 근거(D08) | 판정 불가 회차를 분모에서 분리해 표시 |

모든 시나리오: 두 선수 행동 모두 분류 필요. 사용자 행동만 분류하면 방어·카운터·반격 판정 불가.

## 5. 판단 보류 처리

| 상황 | 처리 |
|---|---|
| 공격은 보이지만 접촉 순간이 가려짐 | 공격 시도는 기록하고 접촉 판정만 보류 |
| 접촉은 확인되지만 부위가 가려짐 | 접촉 있음, 부위 ‘불명확’으로 기록 |
| 앞선 공격의 접촉은 불명확하지만 뒤의 반격·접촉은 보임 | 뒤 사건의 유효 판정은 유지 |
| 반격은 확인되지만 접촉 여부가 불명확 | 반격 있음, 접촉 판단 불가로 분리 |
| 선수 신원이 불명확 | 특정 선수의 확정 집계에서 제외하고 사유 기록 |
| 실제 거리 측정 불가 | 거리 상태·거리 결과와 이에 의존한 문장만 보류 |
| 근거 자체가 없음 | 발생 없음이나 성공으로 바꾸지 않음 |

판정·집계 기록 규칙: 14의 6절. 분할 구간 중복 집계 방지: 08. 상대 반격 집계 가상 예: 02A.

관련: 30 결정해야 할 사항 · 20A 모델 후보와 검증 계획 · 32 데이터 수집과 학습 자료
