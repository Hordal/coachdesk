# 26 측정 데이터 명세
상태: 1단계 기본안. 숫자: 근거가 계산으로 제시된 것 = '계산값', 근거 없이 정한 출발점 = '초기 목표값'(7절 실험으로 확정). 도메인 기준(D01~D10)과 무관한 공학적 요구만 다룸.

## 1. 범위

1단계(기술 인식 + 접촉 여부·부위, 01), 상태 Feature 계산(25), 실제 거리 실험(T02)에 필요한 물리 데이터 결정. 촬영 가이드: 이 문서의 요구를 현장 절차로 이전.

### 이번 단계의 결정(기본안)

| 항목 | 결정 | 이유 |
|---|---|---|
| 관절 좌표 | 2D 화면 좌표 기본 추출 | 1단계 판정·25의 Feature가 2D로 계산 가능. 3D 복원: 카메라·보정 부담이 커 2단계 |
| 실제 거리 | 바닥 평면 보정(바닥 표식 기반) 기본, 선수 키 기반 크기 추정은 교차 확인용 | 바닥에 닿은 발 위치는 평면 보정으로 물리적으로 맞게 구함(03). 키 기반 추정: 원근·자세에 따라 흔들림 |
| 3D | 다각도 동시 촬영본: 2D Feature 시점 의존성 측정에만 사용. 3D 관절 복원 안 함 | 2D 판정이 카메라 각도에 얼마나 흔들리는지 먼저 확인해야 3D 필요성 판단 가능 |
| 이번 단계 비추출 | 3D 관절각, 타격 속도 실제 단위(m/s, 공중 손·발), 충격량 | 카메라 1대 2D로는 근거 있는 값 생성 불가(03·09) |

### 최소 관절 세트(P5)

| 부위 | 관절 | 필요한 이유 |
|---|---|---|
| 머리 | 코 | 가드 높이 기준, 머리–골반 정렬, 접촉 부위(머리) 영역 |
| 팔 | 좌우 어깨·팔꿈치·손목 | 가드, 펀치 궤적·신전, 접촉 부위(가드) 영역 |
| 몸통·다리 | 좌우 골반·무릎·발목 | 자세 높이, 무릎 각도, 킥 궤적, 바닥 위치 |

- 합계 13점(nose, left·right_shoulder·elbow·wrist·hip·knee·ankle) = COCO 17점에서 눈·귀 4점 제외
- 모델이 더 많은 점 제공 시 그대로 보존, 판정은 13점만 요구
- 뒤꿈치·발끝(발 방향·바닥 위치 보정용): 핵심 세트 제외. 발 점 제공 모델(MediaPipe 33점 등) 사용 시에만 추가 관절로 보존(팀 연구 포즈에서 33점 확보, 14의 PoseObservation). 발 점 없음 → 스탠스 판정·발 방향 Feature 계산 안 함, 보류(25)
- 글러브 끝: 관절 아님. 1단계 접촉 판정은 손목 위치 + 글러브 크기 보정으로 근사(24)

## 3. 시간 해상도(프레임률)

| 요구 | 내용 |
|---|---|
| 최대 동작 시각 오차 | 1프레임 이내 목표. 프레임 간격: 30fps 33.3ms, 60fps 16.7ms, 120fps 8.3ms(계산값) |
| 접촉 순간 | 접촉이 보이는 프레임 최소 1장 필요. 접촉 지속 시간: 측정 이력 없음 → 실험 E1 |
| 기술 구간 | 준비~회수 구간에 속도 피크·감속을 구별할 프레임 수 필요 → 실험 E1 |

- 영상 규격: 720p·30fps 이상 기본 지원, 1080p·60fps 권장(최대 길이: 서버 성능 실측 후 결정)
- 30fps: 접촉 판정 결과에 프레임률 병기, E1 결과로 판정 보류 범위 결정
- 검증용 일부 장면: 120fps 이상 촬영
- 고프레임 영상을 줄인 저프레임 영상 ≠ 실제 저프레임 촬영(노출·블러 차이, 20A) → E1은 같은 장면을 여러 기기로 동시 촬영해 비교
- 스마트폰 영상: 가변 프레임률 가능. 05 규칙대로 프레임별 실제 시각(P1) 사용, 명목 fps로 시각 생성 금지

## 4. 공간 해상도(선수 화면 크기)

- 요구: 선수 전신 높이 ≥ 포즈 모델 입력 높이. 많이 쓰이는 top-down 포즈 모델: 사람 영역을 256×192 등 고정 크기로 잘라 입력. 화면 속 선수가 더 작으면 확대되어 세부 손실
- 초기 목표값: 화면 속 선수 키 256px 이상(선택한 포즈 모델 입력 높이로 갱신), 접촉 부위 구분용 권장 400px 이상. 모델 확정 후 E2로 갱신

계산 예시(선수 키 1.75m 가정, 측면 촬영에서 움직이는 영역의 가로 폭 W m가 화면 가로에 꽉 찬 경우):

| 해상도(가로 px) | 1m당 px | 선수 키(px) | 256px 이상 조건 | 400px 이상 조건 |
|---|---|---|---|---|
| 1280(720p) | 1280/W | 2240/W | W ≤ 8.75m | W ≤ 5.6m |
| 1920(1080p) | 1920/W | 3360/W | W ≤ 13.1m | W ≤ 8.4m |
| 3840(4K) | 3840/W | 6720/W | W ≤ 26.3m | W ≤ 16.8m |

- 1080p, W=6m: 1px ≈ 3.1mm. 관절 위치 오차(px): 모델·촬영 조건별 상이 → E2·E3에서 측정
- 해상도: 720p 이상 기본 지원, 1080p 권장. 4K: 저장·처리량 증가(13), E2에서 이득 확인 시에만 사용
- 포즈는 분석 프레임(기본 1280×720)에서 추정 → 선수 키는 분석 프레임 기준, 위 표의 720p 행 적용. 원본 해상도 포즈 별도 추정 여부: E2 결과로 결정

## 5. 실제 거리(바닥 평면 보정)

| 요구 | 내용 |
|---|---|
| 기준 표식 | 바닥에 실제 위치를 아는 표식 4개 이상, 한 직선 위 금지, 선수 이동 영역을 둘러싸도록 배치(평면 변환 계산 최소 4점, 계산값). 검증용 표식 추가 |
| 카메라 | 촬영 중 위치·각도·줌 고정. 전자식 흔들림 보정 끔(화면을 잘라 변형 → 표식 기반 변환 깨짐). 초광각 렌즈: 왜곡 보정 없이 사용 금지 |
| 카메라 높이 | 바닥 평면이 너무 비스듬 → 바닥 위치 오차 증가 / 너무 높음 → 접촉 간격 안 보임. 초기 목표값: 높이 1.5~2m에서 약간 내려다보는 각도(E3에서 확정) |
| 측정점 | 발목·발 중심 = 바닥 점. 공중에 뜬 발(킥 중): 바닥 점 제외 |
| 교차 확인 | 입력 선수 키로 화면 크기를 환산한 거리와 비교. 차이 크면 보정 상태 의심 |
| 실측 참조(P11) | 표식 좌표, 검증 표식 간 거리, 선수 키·리치, 카메라 높이·바닥 거리를 현장 줄자로 측정·기록 |

보정 없음·표식 가림 영상(사용자 업로드 기존 영상 등): 실제 거리 계산 안 함, 거리 의존 판정만 보류(02·03).

## 6. 다각도 동시 촬영과 동기화

| 요구 | 내용 |
|---|---|
| 용도 | 2D Feature·접촉 판정의 시점 의존성 측정(E4). 3D 복원 안 함 |
| 배치 | 측면(두 선수가 마주 보는 선에 수직) 1대 + 대각선 또는 정면 1대 |
| 동기화 | 각 촬영 시작·끝에 소리+빛 신호(박수, 스마트폰 플래시+소리)를 모든 카메라에 기록. 오디오 파형 상호상관으로 오프셋 산출, 시작·끝 오프셋 차이로 시간 흐름 차이(drift) 확인 |
| 허용 잔차 | 초기 목표값: 정렬 후 잔차 ≤ 목표 프레임률 1프레임 |

## 7. 검증 실험

팀 촬영으로 진행. 결과로 3~6절 초기 목표값 확정 + 촬영 가이드 갱신.

| ID | 실험 | 방법 | 측정 값 | 확정할 항목 |
|---|---|---|---|---|
| E1 | 프레임률 | 같은 스파링을 30·60·120fps 이상 기기로 동시 촬영 | 접촉이 보이는 프레임 수, 기술 검출 누락, 최대 동작 시각 차이(120fps 기준) | 최소·권장 프레임률, 30fps 영상의 판정 보류 범위 |
| E2 | 선수 크기 | 같은 장면을 카메라 거리·해상도 변경해 촬영 | 정지 자세 관절 흔들림(px), 빠른 동작 중 손목·발목 누락률 | 최소 선수 화면 크기, 해상도 |
| E3 | 바닥 보정 | 표식 위 알려진 위치에 서고 이동, 카메라 높이 2~3가지 | 추정 바닥 위치 vs 실측 오차(cm), 높이별 차이 | 카메라 높이, 표식 배치, 실제 거리 오차 수준 |
| E4 | 시점 의존성 | 측면·대각선 동시 촬영 | 같은 순간 2D Feature 차이, 접촉 판정 불일치 | 측면 촬영 필수 여부, 2D 판정 허용 각도 |
| E5 | 동기화 | 다각도 촬영 신호 정렬 | 정렬 잔차, 촬영 길이별 drift | 동기화 절차 |
| E6 | 모션 블러 | 조명 밝기·셔터 조건 변경, 빠른 펀치 촬영 | 최대 속도 구간 손목 검출률 | 조명·노출 조건 |

## 8. 촬영 가이드로 넘길 요구 요약

- 720p·30fps 이상 기본 지원, 1080p·60fps 권장, 일부 장면 120fps 이상
- 선수 키 화면 256px 이상(권장 400px), 두 선수 머리~발끝 항상 화면 안
- 삼각대 고정, 줌·흔들림 보정 끔, 초점·노출 고정, 기본 렌즈
- 측면 시점 기본, 높이 1.5~2m에서 약간 내려다봄
- 바닥 표식 4개 이상 + 검증 표식, 줄자 실측 기록
- 다각도 촬영 시 시작·끝 동기화 신호
- 밝은 조명(모션 블러 감소)
- 두 선수 복장·글러브 색 구분(선수 구별·글러브 영역 구분에 유리)
- 촬영 기록: 기기·설정·카메라 위치, 선수 키·리치, 표식 좌표, 참여자 동의
