# 07 선수 추적 복구
상태: 모델 중립 기본안

## 식별 규칙
- participant_id: 영상 안의 선수 / track_id: 연속 추적 조각
- 본인 지정: 첫 프레임 강제 없음, 두 선수가 구별되는 선택 가능 프레임에서 지정
- 자동 연결 근거 불충분 → 미연결 유지

| 사건 | 기본 처리 |
|---|---|
| 짧은 검출 누락 | 추적기 예측과 관측값 구분, 거리 측정에 직접 사용 금지. 같은 track_id로 이어져도 공백을 관측으로 채우지 않음 |
| 교차·신체 겹침 | 위치·움직임·외형 일관성 점검, 모호하면 연결 보류 |
| 화면 이탈 후 복귀 | 새 track 생성, 이전 선수 연결은 별도 검증 |
| 컷 전환 | 추적 초기화, 임의 ID 승계 금지 |
| ID 교체 신고 | 지정 시각부터 해당 연결 정정, 하위 결과 재계산 |

## 추적 입력과 선수 선택
- 신뢰도 임계값(기본 0.4) 이상 검출: 선수 후보 두 명으로 줄이지 않고 전부 추적기에 전달
- 배경 인물: 별도 트랙. 활성 길이·중앙 면적 등 진단 값 = 후보 표시용 참고, 신원 판정 아님
- 추적 종료 후: 후보 트랙·대표 프레임 표시 → 사용자가 USER·OPPONENT 트랙 지정. 한 선수에 트랙 여러 개 연결 가능
- 지정 전 배정 상태: NOT_RUN, 이후 분석 미진행
- 현재 구현: 사용자가 고른 트랙 = USER, 남은 트랙 중 가장 오래 유지된 트랙 = OPPONENT(임시 지정). 사용자 확인 대체 아님. 선수 선택 단계에서는 사용자가 두 선수 모두 지정
- 신원 결정: 입력 순서·화면 좌우 위치 사용 금지. 같은 저장 결과 → 같은 선택 재현. 없는·잘못된 track_id: 오류로 거절
- 위치·움직임·외형 가중치: 초기부터 정답처럼 고정 금지
- 얼굴 인식: 필수 구성 제외
- 실패 사례 포함: 같은 복장, 조명 변화, 카메라 이동

## 검증
- 교차·이탈·재등장 영상: ID switch, 미연결 시간, 잘못 연결 시간 측정
- 검출률 / 선수 연결 정확도: 별도 기록
- 추적기 선택: 동일 자료로 비교
- 두 선수 겹침 구간: 겹치기 전 연속성 / 겹친 동안 동작 / 겹친 뒤 ID 안정성으로 분리 검토
- 정답 자료 없는 동안: ID 교체 비율 등 합격선 임의 설정 금지
- 신뢰도 임계값 미만 검출의 추적 영향: 별도 확인
