# 03 좌표와 실제 크기
상태: 표현 구조 기본안, 실제 크기 복원법은 실험 대상

## 좌표 공간
| 종류 | 기본 정의 |
|---|---|
| coded_px | 부호화 프레임. 좌상단 원점, x 오른쪽·y 아래, px(coded_width·coded_height) |
| display_px | 회전 적용 표시 영상. 원점·축 동일(display_width·display_height) |
| analysis_px | 분석용 파생 영상(기본 1280×720). 검출·추적·포즈 기본 저장 좌표. 표시 영상에서 scale, pad_x·pad_y로 생성 |
| model_local | 모델 고유 좌표. 원점·축·단위·대상 신체 명시 |
| ground_m | 보정한 바닥 좌표. x/y는 기준점으로 정의, m |
| world_m | 공통 3차원 공간. z 위쪽, x/y 방향은 보정 기준으로 기록, m |

- 변환마다 기록: source/target space, 적용 시간 구간, 방법·버전, calibration_id, 유효 상태. 원본 회전·리사이즈·crop 변환 포함
- 다른 공간 값: 변환 없이 비교 금지
- 분석 좌표 → 표시 좌표: FrameTransform(coded·display·analysis 크기, rotation_degrees, scale, pad_x, pad_y). 근거 클립 자르기·화면 오버레이는 되돌린 좌표 사용
- 분석 영상 = 표시 영상을 비율 유지로 분석 크기에 맞춤. scale: 가로·세로 비율 중 작은 값, 남는 곳: 가운데 정렬 패딩
- 변환식: analysis = display × scale + pad. 표시 좌표 = 부호화 프레임에 시계 방향 회전(0·90·180·270도) 적용한 영상의 좌표. 부호화 좌표로 복원: 표시 좌표에서 회전 역적용

## 크기와 보정
- 바닥 평면 변환: 바닥 위 점에만 적용. 공중 손·머리의 3차원 거리 계산 재사용 금지
- 추정한 실제 크기 / 실측 기준 보정값: 출처 구분
- 입력 전제 부족 → 실제 거리값 보류
- 보정 방식 후보 비교: 기준점, 크기 정보, 카메라 정보, 학습 기반 추정
- 현재 확보 영상 조건: 최종 촬영 규격으로 고정 금지

## 검증
- 알려진 위치·간격, 좌표 왕복 변환 시험
- 깊이·시점·카메라 움직임별 오차 분리
