# 04 카메라 움직임
상태: 기술 검증 기본안

## 기본 처리
- 기준선: 선수·심판 등 움직이는 전경 제외, 배경 특징으로 프레임 간 카메라 변화 추정
- 특징 대응·강건 추정 성공 여부 기록
- 평면 변환이 모든 깊이의 움직임을 보정한다는 가정 금지

| 상황 | 처리 |
|---|---|
| 팬·틸트·작은 흔들림 | 배경 기준 변환 시험, 잔차·대응점 분포 검사 |
| 줌 | 보정 유효성 재검사, 이전 크기 변환 무조건 유지 금지 |
| 컷 | 새 구간 시작, 추적·카메라 상태 재설정 |
| 전경이 화면 대부분 점유 | 카메라 추정 불가 표시 |
| 큰 시차·블러 | 단일 평면 변환 적용 보류 |

- 안정화 영상: 파생물, 원본 보존
- 이동 경로: 카메라 보정 유효 시에만 실제 공간 지표로 제공
- 보정 실패 시에도 원본 재생·화면 좌표 관측 유지

## 검증
- 비교 영상: 정지 인물 + 이동 카메라 / 이동 인물 + 고정 카메라 / 둘 다 이동
- 기록: 정지 대상을 움직였다고 계산하는 오차, 컷 탐지 실패
- 알고리즘·임계값: 실험 후 고정
