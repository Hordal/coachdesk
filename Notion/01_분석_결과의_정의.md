# 01 분석 결과의 정의
상태: 제품 범위 정의. 구현 가능성·정확도 미검증.

## 제품 정의
복싱·킥복싱·무에타이·MMA 경기 후 영상 자동 복기 도구. 주요 장면의 시각·설명 제공 → 상태·행동·결과 연결 → 반복 행동·문제·강점, 중요 단발 이벤트 발견 → 바꿔야 할 행동 안내. 반격·피격 관계 포함 분석. 인간 코치: 개발 중 기준 설정·학습 자료·평가 참여. 실사용 시 결과 검토: 필수 절차 아님.

## 결정한 범위
| 구분 | 결정 |
|---|---|
| 대상 | 초급~중급 수련자. 복싱·킥복싱·무에타이·MMA. 영상: 경기·자유 스파링·과제 스파링 |
| MMA 그라운드 범위 | 스탠딩: 기존 타격 분석 유지. 그라운드: 테이크다운(성공·방어·판단 불가), 상하 관계, 탑 컨트롤 시간, 서브미션 종료만 분석, 기술명·세부 포지션 분류 제외(33). 무에타이: 클린치 주요 공격까지 분석 |
| 분석 시점 | 경기 이후, 모든 라운드 포함 영상 |
| 필수 결과 1 | 경기 요약: 주요 장면 타임스탬프, 근거 영상 연결, 짧은 분석 |
| 필수 결과 2 | 습관 피드백: 상황·반복 행동/문제/강점·관측 결과·근거 장면·교정 방향. 반격/피격: 확인 시 연결 |
| 사건 범위 | 공격 시도·명중·빗나감·방어·페인트·거리 조절. 매 순간 분류 불필요 |
| 반격 | 상대 반격 시도와 실제 피격 분리. 피격 없는 반격 시도 포함 |
| 1단계 결과 범위 | 기술 인식 + 접촉 여부·접촉 부위(머리·몸통·다리·가드·불명확). 피격 = '접촉 있음 + 부위'. 명중·빗나감·방어됨·회피됨·방어 성공 판정: 2단계(최종 요구에서 제외 아님) |
| 최소 분석 수준 | 원인 설명 어려우면 특정 행동 이후 반격·피격 횟수·반복 장면 제공 |
| 추가 해석 | 객관적 근거 있으면 공격 기회 노출·원인 해석. 교환 우열·공식 채점: 선택 기능 |
| 반복 문제 범위 | 실제 피격 없어도 전문가 기준 해당 시 가드 복귀 지연 등 기록. 반복만으로 문제 단정·피격 원인 확정 금지 |
| 분석 분류 | '분석 항목 및 판정 구조'의 상태·행동·결과·패턴 체계(목록: 02). 강점·중요 단발 이벤트 포함, 최소 결과 개수 없음 |
| 결과 형태 | 예상 분석 시나리오 1~6: 장면별 행동 전 상태 → 행동 → 결과(행동 후 상태 변화 포함) → 피드백. 판정 일부 보류 시 해당 판정 의존 문장만 제외 |
| 반복 상황 | 동일 전체 물리 상태 아님, 의미상 유사한 상황. 거리: 중요 조건, 분류 기준 검증 필요 |
| 실제 거리 | 피드백 뒷받침용 내부 측정에 필요. 선수 신체 정보: 사전 입력. 입력 리치만으로 실제 공격 가능 범위 확정 불가 |
| 교정 범위 | 바꿔야 할 행동. 구체적 훈련 드릴·다음 영상 개선 추적: 필수 아님 |
| 촬영 | 기존 영상 수용, 권장 촬영 조건에서 품질 향상. 카메라 수·최종 촬영 규격 미확정 |
| 판단 보류 | 허용. 전체 시간 분류율 < 중요 장면·전후 분석 유효성 |

## 사용 흐름 — 화면 설계 기본안

| 단계 | 사용자 행동 | 시스템 표시 |
|---|---|---|
| 1. 영상 등록 | 영상·종목·선수 정보 입력 | 형식·품질 확인 결과, 처리 가능 범위, 부족한 정보 |
| 2. 선수 지정 | 두 선수가 구별되는 프레임에서 본인 선택, 나머지 = 상대 확인 | 선택한 선수. 첫 프레임 선택 강제 없음 |
| 3. 분석 대기 | 진행 확인, 필요 시 취소 | 처리 단계·상태. 근거 없는 완료 예정 시간 표시 금지 |
| 4. 결과 확인 | 요약에서 발견 사항 선택 | 반복 문제·강점·중요 장면·판단 불가, 반복 횟수·근거 시각 |
| 5. 장면 복기 | 관련 구간 재생 | 장면별 상태 → 행동 → 결과, 같은 패턴 장면 묶음 |
| 6. 정정·삭제 | 선수 연결 정정, 오류 신고, 의도 설명, 삭제 | 정정 영향·재계산 상태. 자기 설명과 AI 관측 구분 |

- 레이아웃·세부 입력 필드·신체 정보 측정 방법: 미정
- 의도 설명·신고: 검토 없이 정답·학습 자료로 사용 금지

## 사용자에게 제공하는 결과

- 형태: 분석 항목 및 판정 구조의 예상 분석 시나리오 1~6. 각 장면: 행동 전 상태 → 행동 → 결과(행동 후 상태 변화 포함) → 피드백
- 시나리오 피드백 문장 = 필요한 판정이 모두 유효할 때의 목표 문장. 일부 보류 시 해당 판정 의존 문장만 제외
- 시나리오별 필요 판정: 29의 4절

| 시나리오 | 결과 유형 | 핵심 표시 내용(1단계) |
|---|---|---|
| 1. 적절한 거리에서 공격 성공 | 단일 장면 · 강점 후보 | 공격 거리, 머리·몸통 접촉, 공격 후 가드·밸런스 회복 |
| 2. 사거리 밖에서 공격 시도 | 단일 장면 · 문제 후보 | 공격 시 거리, 접촉 없음, 공격 후 밸런스 변화 |
| 3. 하이가드로 공격 방어 | 단일 장면 · 강점 후보 | 상대 공격, 블록 동작, 가드 접촉, 방어 후 자세 유지 |
| 4. 회피 후 카운터 공격 | 연결 장면 · 강점 후보 | 상대 공격 접촉 없음, 후속 공격 연결, 후속 공격 접촉 |
| 5. 후퇴 중 밸런스 불안정 | 단일 장면 · 문제와 성공 분리 | 거리 확보와 일시적 밸런스 불안정 분리 설명 |
| 6. 반복적인 가드 복귀 실패 | 반복 패턴 · 반복 문제 | 같은 행동 뒤 반복된 결과의 횟수·근거 장면 |

1단계 표현: '명중' = '접촉 확인(부위)', '빗나감·회피됨' = '접촉 없음', '방어됨' = '가드 접촉'. '방어 성공', '회피로 피했다' 같은 결과 평가 표현: 2단계 결과 판정 이후 사용.

### 판정 보류 예 — 시나리오 2

- 2단계, 모든 판정 유효: "크로스 시점에서 상대가 유효 펀치 거리 밖에 있었으며, 공격 이후 상체가 앞으로 크게 이동해 밸런스가 불안정해졌습니다."
- 1단계, 실제 거리 측정 불가: "크로스에서 상대와의 접촉은 확인되지 않았고, 공격 이후 상체가 앞으로 크게 이동해 밸런스가 불안정해졌습니다. 공격 시 거리는 측정하지 못했습니다."

### 반복 패턴 예 — 시나리오 6

"크로스 6회 중 4회에서 공격 후 뒷손 가드 복귀 지연이 확인되었습니다." 일부 회차가 가려져 판정 불가 → 판정 가능 횟수 + 판단 불가 횟수 병기.

### 상대 반격 예

시나리오 4가 사용자의 카운터라면 사용자 공격 뒤 상대 반격도 같은 구조로 집계. 가상 예제·집계 결과: 02A. 이 자료만으로 원인 언급 불가 → 관찰·집계만 제공, 교정 방향 미제공 표시.

## 결과를 표현하는 규칙
- 관찰·집계·원인 가설·교정 방향 구분. 행동 후 피격 = 시간적 관계, 원인 입증 아님
- 집계에 분모·판정 불가 건수 병기. 예: 발차기 13회 중 후속 상황 판정 가능 10회, 피격 8회, 판정 불가 3회. 8/13을 확정 피격률로 사용 금지
- 명중 관찰 → 공식 득점 변환 금지. 가드 접촉·신체 접촉·규칙상 유효타 경계: 별도 정의
- 확실한 발견만 제공. 교정 근거 부족 → 관찰·집계까지만, 부족한 부분 명시. 제품 가치 충분 여부: 사용자 평가로 검증
- 원인 분석용 앞뒤 구간: 행동의 시작·종료 기준. 기존 2초 = 임시 처리 여유, 분석 맥락 길이 확정값 아님
- 분석 작업 상태(completed/partial/failed 등) / 결과별 상태(VALID/UNKNOWN/UNSUPPORTED/ERROR) 구분, 분석 가능 범위와 함께 표시. 정의: 14. 결과 없음 ≠ 문제 행동 없음
- 스탠스 자체 좋고 나쁨 판정 금지, 상황 해석 정보로 사용
- 모델 점수 = 정확도 확률 표시 금지
- 원본 만료 시 장기 보관 결과에 근거 영상 만료 표시
- 부상 진단, 심리·피로 단정, 위험한 훈련 처방: 제공 금지

## 다음에 확인할 제품 경계
1. 피격/명중 정의: 가드 접촉 포함 여부, 신체 접촉·유효타 구별 수준
2. MMA 그라운드 사건(33)의 최소 유지시간·병합 간격, 제품 활성화 기준: 라벨 데이터로 결정

무에타이 클린치 주요 공격 분석, 경기·자유 스파링·과제 스파링 전부 지원: 제안안(30의 P01·P02).

## 구현 기본 결정

- 채택: 사건·관계·집계·주장 분리하는 14의 계약
- 각 판정 독립 보류 가능. 숫자·시각: 구조화된 값에서 생성
- 코칭 기준 없음 → 관찰·집계만 제공, 교정 미제공 명시
- 근거 추적·단계별 평가: 18·19
- 포즈 시계열 기반 상태·행동·결과 처리 + 02의 분류 목록 사용
- 미확정: 세부 도메인 판정 기준, 카메라 구성, 모델 선택
