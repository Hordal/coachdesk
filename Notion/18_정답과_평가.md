# 18 정답과 평가
상태: 단계별 평가 구조 채택. 도메인 정답·수치 통과 기준: 전문가 검토·실험 필요.

## 단계별 평가

| 평가 대상 | 참조 자료 | 따로 확인할 오류 |
|---|---|---|
| 시간·회전 | 원본 디코딩 결과·통제 영상 | 시각·좌표 대응 오류 |
| 선수·신체 부위 연결 | 사람의 선수 ID·부위 소속·구간 주석 | ID 교체·좌우/소속 혼동·미연결 |
| 관절 위치·실제 거리 | 가시성 주석·실측 참조·측정 절차와 오차 | 위치/거리 오차·편향·큰 오차·미산출 |
| 상태 판정 | 전문가 표시 거리·가드·스탠스·밸런스 구간 | 상태 혼동·전환 시각·가림 시 과도한 단정 |
| 사건 탐지·분류 | 버전 있는 02 정의 + 전문가 사건 구간 | 누락·오탐·분류 혼동·시작/끝 오차·구간 경계 중복 |
| 접촉·반격 판정 | 개별 판정·사건 관계의 전문가 주석 | 1단계: 화면상 겹침의 접촉 오탐·접촉 누락·머리/몸통/가드 부위 혼동·잘못된 반격 연결. 2단계: 시도/명중 혼동 |
| MMA 그라운드 사건(33) | 2명 이상 독립 라벨링한 Takedown·Ground Relation·Top Control·Submission Finish 구간 + Unknown 구간 | Precision·Recall·F1, 시작·끝 시각 오차, Unknown 비율, 중요 사건 누락률. Takedown 성공·방어 혼동, Top 판정 오류, 통제 시간 오차, 종료 맥락 혼동 |
| 반복 집계 | 같은 입력 사건에 대한 수작업 검산 | 중복·분모/분자 오류·미판정 오처리·정상 스타일을 문제로 판정 |
| 경기 요약 | 전문가 지정 중요 장면·근거 | 중요 장면 누락·잘못 포함·시각 불일치 |
| 원인·교정 피드백 | 전문가 검토 적용 조건·예외·근거 사례 | 근거 없는 원인 주장·부적절한 교정·필요한 교정 미제공·보류된 판정 의존 문장 |
| 출력 문장·근거 | 구조화된 원자료·집계·Evidence | 숫자/시각 불일치·끊어진 근거·보류 사유 누락 |

- 사건 ↔ 정답 일치 판정: 선수·유형·시간 조건 + 일대일 대응. 한 정답 사건 중복 일치 집계 금지
- 구체 시간 허용치·종목별 분류 단위: 전문가 사례·실험으로 결정
- 핵심 장면 탐지 누락 / 피드백의 잘못된 단정: 따로 보고. 모든 단계에 하나의 Precision/Recall 우선순위 강제 금지

## 자료 제작과 분리 — 확정

- 가상 자료: 계약·집계 검사에만 사용, 실제 영상 성능 수치 제외. 모델 예측·사용자 신고: 검토 없이 정답 금지
- 주석 기록 항목: video_id, 대상 선수, 원본 구간, 정의 ID·버전, 판정·사유, 근거, 작성자·검토 상태·수정 이력. 사건 간 관계: 양쪽 사건 ID
- 해당·비해당·판단 불가 사례 포함. 전문가 간 의견 차이 보존, 미해결 사례를 확정 정답으로 덮어쓰기 금지. 검토자 1명 → 독립 검토 미실시 기록
- 같은 경기의 모든 시점 영상·파생 클립: 같은 데이터 분할. 처음 보는 선수·장소 평가: 그 단위로도 분리. 학습·개발 검증·최종 평가 자료 구분, 최종 평가를 반복 조정에 사용 금지
- 자료·전문가 수: 미정. 필요 조건·오류 유형·평가 정밀도 기준으로 산정. 주석 도구·추가 학습 방식: 별도 선택

## 보고 규칙 — 확정

- 전체 자료 수 + 조건별 결과 병기
- 판정 사례의 정확도 외 보류·미지원·실패 수, 중요 장면 분석 가능 비율 보고
- 미탐지 사건: 이미 발견한 사건의 미판정 수와 별개로 평가
- 중요 장면 보류: 유효 분석 제공 실패 사례로 드러냄
- 집계 로직 평가: 정답 사건 입력 / 전체 경로 평가: 모델 추출 사건 입력. 차이로 집계 오류와 상위 인식 오류 구별
- 구조화된 문장 검사 통과 ≠ 교정 방향 정당성 → 코칭 평가 별도 수행
- 거리·추적 등 수치 평가: 참조값 있는 조건에서 수행. 보이지 않는 관절을 확정 정답으로 만들기 금지. 허용 오차·성능 목표·중요도 가중치: 임의 확정 금지

## 당장 가능한 계약 검사

- 02A 가상 예제 두 개 = 회귀 검사 입력
  - 상대 반격 예제 집계: 확인된 발차기 5, 반격 판정 가능 4, 반격 있음 3, 반격에서 머리 접촉 2, 반격 없이 종료 1, 후속 미판정 1
  - 시나리오 6 예제 집계: 확인된 크로스 6, 복귀 판정 가능 6, 복귀 지연 4, 지연 없음 2. 반복 문제·교정 문장 보류
- 추가 검사: 행동 전·후 상태 참조 누락 → 관련 결과 판정 보류 / 크로스 1회 판단 불가 변경 → 분모 5·판단 불가 1 분리 / 분모 0 → 비율 null / 중복 접촉 → 접촉된 공격 수 불변 / 반격했으나 접촉 없음 → 반격만 증가 / 접촉 있음·부위 불명확 → 머리 접촉 집계의 판단 불가로 분리 / 거리 결측 → 거리 관련 주장만 보류 / 입력 정정 → 의존 결과 갱신 / 원본 만료 → 근거 재생 불가 표시
- 구현 완료(`tools/contract_check` 자동 검사): 집계 재계산, 판단 불가 분리, 분모 0, 중복 후보, 부위 불명확, 참조 누락, 보류 규칙
- 미구현: 입력 정정에 따른 갱신, 원본 만료 표시(실제 처리 흐름 구현 후 추가)
