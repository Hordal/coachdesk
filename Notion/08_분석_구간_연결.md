# 08 분석 구간 연결
상태: 처리 기본안

## 구간 규칙
- 초기 실험값: 30초 핵심 구간 + 앞뒤 2초 문맥. 동작 의미 기준 아님, 메모리·처리 실험 설정. 모델 입력 길이에 맞춰 변경 가능

- 핵심 구간 [start, end)의 결과만 해당 작업이 소유. 문맥 중복 집계 금지
- 추적: 가능한 한 시간순 처리, 상태를 다음 구간으로 전달. 독립 병렬 추적은 기본 사용 안 함
- 결과 시간: 05의 원본 시간. 컷·시간 불연속에서 상태 단절
- 구간을 넘는 사건: 근거·시간 연속성 검사 후 병합, 연결 불명확 시 별도 후보로 보존
- 통계: 구간 평균의 단순 평균 금지, 유효 시간·관측 기회 합산 후 재계산

## 검증
- 같은 영상의 전체 처리 결과 vs 분할 결과 비교
- 경계에 동작·가림·라운드 전환 배치: 중복·누락·ID 교체 확인
- 문맥 길이·배치 크기: 이 결과로 조정

## 사건·집계 연결 — 확정
- 분할 구간의 후보 사건 연결 → 동일 논리 사건에 대표 ID 하나 부여
- 후보 → 대표 매핑 보존, Aggregate는 대표 ID로 집계
- 동일 사건 미확정 후보: 확정 횟수에 중복 포함 금지, 미해결 표시
- 병합의 도메인 기준·시간 허용치: 02·18에 남김
- counting_unit 구분: 공격당 반격 여부 vs 개별 반격 공격/접촉 횟수
- 분자·분모·미판정·제외 집합 저장, 정의된 전체 범위에서 재계산. 구간별 비율 단순 평균 금지
- 공방 경계 ≠ 고정 처리 구간 경계
