# 16 분석 재현성
상태: 기록 기본안

## 실행 명세
run에 연결할 항목: 원본 체크섬, 코드 commit, 모델 이름·가중치 체크섬·라이선스 참조, 설정, 전처리, 지표 정의, 스키마, 의존성 lock, 실행 장비·드라이버, 난수 seed, 입력 정정 버전. 비밀키·개인정보: 명세 제외.

## 재실행 규칙
- 이전 결과: 불변 산출물로 보존, 새 실행을 parent_run_id로 연결
- 같은 입력·버전에서도 비결정적 결과 가능, 기록. seed만으로 동일성 보장 안 함
- 값 비교: 지표별 허용차 + 상태·ID 연결 함께 검사. 허용차: 18의 평가 기준
- 캐시: 입력·설정·가중치·정정 버전 일치 시에만 재사용. 사용자 권한 경계 간 공유 금지
- 원본 만료 시 provenance_only 표시. 기록 잔존 ≠ 재실행 가능

## 검증
- 같은 장비 반복 실행 vs 다른 장비 실행 차이 측정
- 모델 교체 시 이전 결과의 버전 불변 확인
- 삭제 정책 > 재현성. 장기 원본 보관을 암묵적으로 요구하지 않음
