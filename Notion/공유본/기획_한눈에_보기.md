# 기획 한눈에 보기 (2026-10-07 기준)

## 1. 제품

- 한 줄: 격투기 경기 후 영상에서 두 선수의 공방을 근거 장면과 함께 정리하는 복기 서비스. 복싱·킥복싱·무에타이·MMA
- 분석 흐름: 포즈 → 상태 → 행동 → 결과 → 사건 → 패턴 → 피드백
- 1단계: 기술 인식, 접촉 여부와 부위, "확인된 N회 중 M회" 집계와 근거 장면
- 1단계 제외: 명중·방어 판정, 공식 채점, 근거 없는 원인·교정
- MMA: 스탠딩은 기존 타격 분석 그대로. 그라운드는 테이크다운·상하 관계·탑 컨트롤 시간·서브미션 종료만 분석. 기술명·세부 포지션은 분류 안 함
- 표시 원칙: 판단 불가를 0으로 표시 안 함. 모든 문장에 근거 장면 연결. 정확도 백분율 표시 안 함
- 구성: Python 서버 + 클라이언트. 현재 클라이언트: 웹 화면(React, UI 구성 확인용). 데스크톱·모바일 확장: 목표, 방식 미정

## 2. 판매

| 단계 | 대상 | 내용 | 다음 단계 조건 |
|---|---|---|---|
| 0. 내부 시험 | 팀 | 팀 촬영 영상으로 1단계 기능 완성 | 완료 기준 달성 |
| 1. 체육관 안의 개인 | 체육관에서 훈련하는 개인 | 개인에게 직접 판매. 무료·할인으로 시작해 반응과 오류 수집 | 반복 사용, 실제 복기 활용, 영상 1건당 처리 비용 실측 |
| 2. 체육관 | 체육관 | 체육관 단위 계약. 1단계 사용자가 있는 체육관부터 | 체육관의 유지 의사 |
| 3. 완전 상용 | 체육관 밖 개인, 아마추어 대회·리그 | 일반 판매. 대회·리그는 2단계 결과 판정 추가 후 | 개인 촬영 영상의 분석 품질, 2단계 검증 |

- 개인 우선 이유: 관장·코치 설득보다 회원 개인 영업이 쉬움. 최우선 과제 = 첫 사용자 확보
- 약점: 촬영 조건 편차, 상대 선수 동의
- 시장의 빈틈: 두 선수 공방 + 근거 정리 서비스 드묾 / 판단 불가 별도 표시 서비스 없음 / 킥·무에타이·국내 체육관 겨냥 서비스 없음
- 경쟁: 개인용 분석 앱(HitSmart, BRAWLER, Punch AI, mmaGPT), 체육관 플랫폼(FormMatch, Ringwork), 경기·대회용 분석(Jabbr, 시드 투자 500만 달러)
- 가격: 구독 + 월 분석 횟수 상한 + 초과 시 크레딧(기본안). 경쟁 앱 월 9.99달러·5회 7.99달러. 상한: 월 5달러·크레딧 건당 약 0.8달러(임시). 하한: 10분 영상 건당 GPU 비용 0.11~0.71달러(추정). 확정: 팀 회의
- 위험: 경쟁 앱의 개인 시장 선점, 촬영 조건 편차에 따른 품질 불안정, 영상 권리·개인정보
