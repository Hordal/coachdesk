## 1. MMA 그라운드

스탠딩: 기존 타격 분석 유지. 기술명·세부 포지션: 분류 제외.

| 사건 | 뜻 | 결과값 |
|---|---|---|
| 테이크다운 | 시도자·방어자, 시도 결과 | 성공, 방어됨, 판단 불가 |
| 그라운드 관계 | 그라운드 상태의 상하 관계 | 상하 명확, 얽힘, 전환 중, 판단 불가 |
| 탑 컨트롤 | 위 선수가 아래 선수의 이동·자세 회복을 제한한 구간과 누적 시간 | 구간, 시간 |
| 서브미션 종료 | 서브미션 상황의 탭·심판 중단 종료 | 경기 승리, 스파링 탭, 판단 불가 |

- 판단 불가 구분
  - 사건 존재 자체 불확실 → 사건 상태: 판단 불가
  - 사건 확실, 결과만 불명확 → 사건 상태: 유효, 결과: 판단 불가
- 탑 컨트롤 시작 시각: 최소 유지시간 충족 후 확정, 실제 통제 시작 시점으로 소급
- 값 없음: 최소 유지시간, 이벤트 병합 간격, 테이크다운 결과 확정 대기 시간(라벨 분포로 결정)
- 구현: 종목 MMA 선택, 그라운드 사건 구조, 파이프라인 출력 변환, 사건 상세 화면. 판정 방법 없음
- 서브미션 종료 선수 필드명(`actor_participant_id`, `target_participant_id`): 임시, 제안서에 이름 없음

## 2. 가격

기본안: 개인 월 구독 + 월 분석 횟수 상한, 초과분 크레딧 추가 결제.
이유
- 영상별 결제 → 업로드 망설임 → 반응 수집 감소
- 횟수 상한 → 월 비용 제한
- 초과 사용 → 크레딧으로 가격 반영

| 항목 | 값 | 상태 |
|---|---|---|
| 구독료 | 월 5달러 이하 | 임시(상한) |
| 크레딧 | 건당 약 0.8달러 이하 | 임시(상한) |
| 월 분석 횟수 상한 | 건당 비용 × 횟수 < 구독료. 비용 추정 가정: 월 4건 | 미정 |
| 무료 범위 | 영상 길이·횟수 상한 | 미정 |

진행 순서
1. 결제 없이 시작: 무료 범위 상한만 설정, 사용량·영상 길이 분포 기록
2. 분석 모델 확정 후 영상 1건당 처리 비용 측정
3. 측정 단가로 월 횟수 상한·구독료 결정

비용 예상 초과 또는 사용량 편차 큼 → 크레딧 중심 전환. 체육관 정액: 첫 사용자 반응 후 결정.

## 3. 가격 상한과 하한

- 상한: 경쟁 가격의 1/2. 경쟁 앱 월 9.99달러, 5회 크레딧 7.99달러(건당 약 1.6달러)
- 하한: 영상 1건당 처리 비용. 10분 영상 GPU 비용 추정, GPU 단가 시간당 0.35~0.7달러(RTX 4090급 클라우드) 가정

| 시나리오 | 가정 | 건당 비용 | 월 4건 |
|---|---|---|---|
| 낙관 | 영상 준비 1분, 검출·추적은 모델 추론 속도(영상 길이의 0.8배), 포즈·판정은 영상 길이의 1배 | 0.11~0.22달러 | 0.4~0.9달러 |
| 비관 | 영상 준비 1분, 검출·추적은 현재 시제품 속도(영상 길이의 4배), 포즈·판정은 영상 길이의 2배 | 0.36~0.71달러 | 1.4~2.8달러 |

- 포즈·행동·접촉 판정 처리 시간: 미측정, 가정. 검출·추적이 현재 속도일 때 이 단계가 영상 길이의 약 3배(GPU 시간당 0.7달러 기준) 초과 → 건당 비용이 크레딧 상한 초과
- 저장 비용: 영상 1시간 약 0.01달러. 미포함: 서버 고정비, 결제 수수료, 실패·재시도 비용, 인건비
- 실측: 17초 영상(407프레임) 검출 초당 6.1프레임, 모델 추론만 초당 29.8프레임, 추적 0.07초. 프레임당 시간의 77%가 전처리. 이전 수치 "17초 영상 약 4분"은 오버레이 생성 시간 포함, 정정

## 5. 데이터셋과 모델 조사

상업 이용 가능한 격투기 데이터셋·사전학습 가중치(포즈·행동·접촉): 못 찾음. 핵심 자료: 팀 촬영 영상 + 라벨링.

| 자료 | 내용 | 판정 |
|---|---|---|
| BJJ Positions(ViCoS) | 이미지 120,279장, 18개 포지션 클래스 | CC BY-NC-SA, 불가 |
| MMA 포즈(Mendeley) | UFC 방송 이미지 5,109장 | CC BY-NC-SA, 불가 |
| Olympic Boxing, BoxingVI | 복싱 펀치 영상 | 불가 |
| Hugging Face BJJ | 샘플 1개, 출처 불명 | 사용 불가 |
| RTK Motion BJJ | 모션캡처 76초, 상업 라이선스 | 분량 부족 |
| Roboflow MMA 이미지 모음 | 수백~2,000장, CC BY 표기 | 이미지 출처 미확인, 제외 |

- 그라운드: 이미지 단위 포지션 라벨뿐. 시간 구간 라벨(테이크다운 시도·결과, 서브미션 종료) 공개 자료 없음. 무에타이·킥복싱 영상 데이터셋도 없음
- 검출 모델: 상업 이용 확정 후보 없음. RF-DETR은 코드·COCO 사전학습 가중치 Apache 2.0, COCO 이미지 이용 약관 위험 잔존. Open Images 직접 미세조정안: 미시험, 법률 검토 필요
- 접근 불가·미확인: Roboflow, 논문, OpenFSW 저장소. 검색: 영어 위주
