# 09 오차의 전달
상태: 불확실성 관리 기본안

## 원칙
- 검출 score, 포즈 score, 실제 거리 오차, 해석 신뢰도: 하나의 점수로 합산 금지
- score 곱 = 정확도 확률 제시 금지

| 단계 | 기록할 오류 |
|---|---|
| 시간·회전 | 시각 대응·좌표 변환 오류 |
| 선수 연결 | 잘못 연결·미연결 구간 |
| 자세 | 관절 위치 잔차·가림·좌우 혼동 |
| 보정 | 기준점·크기·카메라 변환 오차 |
| 지표 | 입력 변화에 대한 출력 민감도 |

- 필수 입력 결측 → 결과 보류 전파
- 연속값 오차: 실제 참조 자료 또는 근거 있는 입력 오차 모형으로 전파
- 상관된 오차: 독립 가정 금지
- 검증되지 않은 ±오차 범위 표시 금지

## 검증
- 관절·시간·보정값을 통제 범위에서 변경 → 지표 변화 측정
- 속도 등 차분 값: 노이즈 증폭 별도 검사
- 평활화의 지연·최댓값 손실 기록
- 허용 오차: 지표별 활용 목적과 함께 18에서 결정
