# 20 외부 의존성
상태: 의존성 관리 기본안

## 선택·기록
- 대상: 라이브러리, 모델 가중치, 데이터셋, 외부 서비스
- 기록 항목: 이름, 버전, 출처, 라이선스, 재배포·상업 이용·학습 조건, 비용·한도, 개인정보 전송 여부, 대체 방법
- 코드 라이선스 / 가중치·데이터 라이선스: 별도 확인

## 기본 규칙
- 무료 ≠ 서비스 이용·배포·학습 허용
- 원격 API: 명시적 설정 없으면 호출 금지. 키 없을 때 다른 외부 제공자로 조용히 전송 금지
- 모델 어댑터: 14의 표준 출력으로 변환. 모델 교체로 관절 개수·좌표·score 의미 변경 시 명시적 매핑
- 의존성·가중치 버전 고정, 업데이트 전 기존 평가 자료로 확인
- 외부 서비스 실패: retryable 오류 / 한도·인증·정책 오류 구분

## 검증
- 시험: 네트워크 차단, 키 누락, 제공자 오류, 모델 파일 누락
- 기록: 실행 필요 파일 목록, 오프라인 실행 가능 여부
- 유료 비용 발생 경로: 기본 비활성화
