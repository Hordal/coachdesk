# 15 데이터 수명
상태: 원본 단기·결과 장기 보관은 기획 결정. 기간 숫자는 잠정 운영안

## 보관 기본안
| 종류 | 기본안 |
|---|---|
| 원본·재생본·근거 클립·추출 이미지 | 분석 종료 후 7일(임시) 자동 삭제. 모든 복제·진단 이미지 적용 |
| 미완성 업로드·임시 처리 파일 | 작업 종료 후 정리. 고아 파일: 24시간(임시) 이내 정리 목표 |
| 구조화된 결과·정정·버전 기록 | 계정 유지·서비스 목적 유효 기간 보관, 사용자 삭제 지원 |
| 운영 로그 | 30일(임시) 순환 보관, 민감 내용 최소화 |
| 학습·평가 자료 | 학습·평가 이용 동의: 서비스 이용의 필수 조건(30의 P05). 동의 후에도 원본 자동 복사 금지. 별도 적법한 처리 근거·목적·보관 정책 검토 전 학습 파이프라인 반출 금지 |

- 7일·24시간·30일: 임시 값, 법정 기간·확정 숫자 아님. 외부 시험 전 설정값·고지·운영 가능성 확인
- 장기 보관 ≠ 무기한 보유 보장. 계정 종료·목적 종료·삭제 요청 반영

## 삭제 절차
- 순서: 요청 즉시 조회 차단·실행 취소 → 원본에서 파생 관계 추적 → 파일·DB·캐시·진단 자료 삭제 → 결과 상태 기록
- 삭제 작업: 재시도 가능, 완료 전 '완료' 표시 금지
- 원본 만료 후: 요약·수치 유지, 근거 영상 만료 표시, 원본 재업로드 없이 재계산 불가
- 백업: 단기 원본 기본 제외. 결과 백업 보유·복구 정책 결정, 복구 시 삭제 표식 재적용
- 이미 학습된 가중치의 삭제 영향 제거 ≠ 파일 삭제: 별도 정책 없이 완료 약속 금지

## 검증
- 한 영상 삭제 시 원본·재생본·이미지·임시 파일·연결 캐시까지 잔존 없음 확인
- 원본만 만료: 장기 결과 정상 표시 + 근거 재생 불가 표시 확인

## 구현 반영
- 영상·결과 전체 삭제: 요청 즉시 조회 차단 → 진행 중 작업 취소 요청 → 작업 정지 후 원본·재생용 사본·임시 파일·가져온 검출·추적 결과 파일 삭제 → 잔존 파일 없음 확인 → DB 행 삭제(작업, 실행, 정정, 신고, 의도 설명, 선수 지정, 업로드 기록)
- 파일 삭제 실패·작업 진행 중: '삭제 중' 상태 유지, 워커가 10초마다 재시도, 완료 전 '완료' 표시 금지
- 원본·재생용 사본만 삭제 가능: 요약·수치 유지, 근거 영상 '삭제됨' 표시
- 영상 준비 후 7일 경과 → 워커가 원본·재생용 사본 만료 처리. 기간: 환경 변수, 0이면 자동 삭제 안 함. 7일은 임시 값
- 미구현: 백업 삭제 표식 재적용, 운영 로그 30일 순환, 학습 파이프라인 반출 금지
