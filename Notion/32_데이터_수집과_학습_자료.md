# 32 데이터 수집과 학습 자료
상태: 기본안. 수량·라벨링 도구 미정, 30의 결정 항목(T04·T10)으로 관리.

분석 흐름 단계별 학습·평가 자료, 라벨 기준, 영상 확보 방식. 주석 항목·자료 분할(학습·개발 검증·최종 평가): 18의 '자료 제작과 분리'.

## 1. 단계별 필요 자료

모든 단계: 평가용 정답 필요. 학습까지 필요한 단계: 일부. 최대 작업: 행동 판정 학습 자료.

| 흐름 단계 | 후보(20A) | 학습 필요 여부 | 필요한 라벨 | 비고 |
|---|---|---|---|---|
| 선수 검출·추적 | RF-DETR·RTMDet, ByteTrack·BoT-SORT | 사전학습 모델 사용. 평가용만 | 프레임별 선수 ID(사용자/상대), 교차·재등장 구간 | 격투기에서 실패가 많으면 추가 학습 검토 |
| 포즈 추적 | RTMPose(COCO 전용 가중치), MediaPipe | 사전학습 모델 사용. 평가용만 | 일부 프레임의 관절 위치와 보임/가림 표시 | 보이지 않는 관절을 정답으로 만들지 않음 |
| 상태 판정 | 관찰 Feature + 판정 기준 | 규칙 방식이면 불필요, 학습 방식이면 필요 | 선수별 거리·가드·스탠스·밸런스 구간과 판단 불가 구간 | 앞손/뒷손은 스탠스와 함께 표시 |
| 행동 판정 | LSTM / Transformer Encoder | 필수(격투기 가중치 없음) | 선수별 행동 구간과 기술명(세부 분류), 기술 판정 단계 시각, 판단 불가 | 두 선수 모두 라벨. 1회 단위는 임시 운영 정의(24) 후 D05로 대체 |
| 결과 판정(1단계: 접촉) | 포즈 기하 규칙 / 영상 클립 분류(T03) | 규칙 방식이면 평가용만, 클립 분류면 필수 | 공격 행동별 접촉 여부(있음·없음·판단 불가), 접촉 시각, 접촉 부위(머리·몸통·다리·가드·불명확) | 명중·방어됨·회피됨 라벨은 2단계에서 같은 사건에 추가 |
| 그라운드 사건(MMA) | 포즈+bbox+상대 위치+시간 특징 기준선, 영상 시간 분류기 결합(33) | 필수(격투기 가중치 없음) | Takedown 시도·결과, Ground Relation 구간, Top Control 구간, Submission Finish 구간과 종료 맥락, 관찰 불가 구간 | 라벨 기준은 33의 8절. 2명 이상 독립 라벨링으로 불일치 사례를 정리하고 같은 영상·선수가 학습·검증·평가에 섞이지 않게 분할 |
| 사건 정리·패턴 | 규칙·집계 | 불필요 | 시간적 후속 공격 관계, 공방 경계. 반격·카운터와 반복 문제·강점은 D06·D08 이후 | 집계 로직 검산과 전체 평가에 사용 |
| 피드백·요약 | 템플릿 | 불필요 | 도메인 기준으로 지정한 중요 장면, 피드백 문장의 적절성 | 예상 분석 시나리오 1~6이 첫 평가 목록 |

## 2. 라벨링 기준

- 라벨 이름: 분석 항목 및 판정 구조의 분류 이름 그대로
- 각 라벨에 판정 기준 버전 기록. 도메인 기준(D 항목) 확정 전: 임시 운영 정의(24) 버전 기록, 확정 시 영향 라벨만 재검토. 버전이 다른 라벨 혼합 금지
- 시각: 원본 재생 시각
- 행동 라벨: 시작·끝 + 최대 동작 시점 기본 표시(기본안). 기술 판정 6단계 중 추가 표시 단계: D05
- 결과 라벨: 행동 라벨과 같은 사건 ID에 연결. 사건 간 관계: 양쪽 사건 ID 기록

## 3. 첫 라벨링 범위 — 기본안

예상 분석 시나리오 1~6에 등장하는 판정부터 라벨링. 시나리오가 요구하는 판정이 갖춰져야 첫 실제 영상 검증(31의 1절 3단계) 가능.

| 분류 | 우선 라벨링 항목 | 관련 시나리오 |
|---|---|---|
| 상태 | 거리(사거리 밖·킥·펀치·근거리), 가드(중립·하이가드), 밸런스(안정·불안정·리커버링) | 1·2·3·5 |
| 행동 | 잽·크로스, 블록·슬립, 전진·후퇴·진입 | 1~6 |
| 결과 | 접촉 여부·접촉 부위, 거리 확보, 공격 후 가드 복귀 | 1~6 |

나머지 세부 분류(훅·어퍼컷·킥·니킥, 패리·덕킹 등): 첫 검증 결과 후 확장.

## 4. 영상 확보

제품용 모델: 팀 촬영 영상 + 이용 동의 사용자 영상으로만 학습.

| 경로 | 장점 | 확인 사항 |
|---|---|---|
| 팀 자체 촬영 스파링 | 촬영 조건 통제, 실측 참조 확보 가능, 권리 문제 최소 | 참여자 동의, 종목·실력 다양성 |
| 체육관 사용자 영상 | 실제 사용 조건과 같음 | 학습·평가 이용 동의(P05·P10), 상대 선수 동의 |
| 공개 경기 영상·공개 데이터셋 | 양이 많음 | 확인한 데이터셋은 모두 상업 이용 불가. 라벨 체계·촬영 조건 설계 참고용 |
| 팀 연구 테스트 영상 6개(Pexels) | 확보됨, 가림·관중·세로 포함 | 출처 URL은 클립 01만 기록, 재배포·AI 학습 권한 `PENDING_REVIEW`. 기능 시험·평가용, 학습 자료로 쓰지 않음. 팀 분석 출력(포즈·동작 후보·의사 라벨)은 AI 예측이며 정답 라벨이 아님 |

- 공개 데이터셋(Olympic Boxing Punch Classification Video Dataset, BoxingVI) 내용·이용 조건: 24의 4-2절
- 촬영 요구(프레임률·해상도·바닥 표식·동기화)·촬영 기록 항목: 26

## 5. 수량 산정

1. 3절의 첫 라벨링 범위에서 시작
2. 기술별·종목별 해당·비해당·판단 불가 필요 사례 수: 기준선 실험으로 추정
3. 상태·결과 라벨: 행동 라벨을 붙인 구간에 함께 부착 → 작업량 감소
4. 시나리오 1~6 해당 장면: 평가 자료에 최소 1회씩 포함

## 6. 라벨링 도구

- 필요 기능: 구간 라벨(상태·행동), 사건 간 관계, 일부 프레임 관절 수정
- 후보 비교: 영상 구간·키포인트 라벨 지원 도구(CVAT, Label Studio 등). 내보내기 형식의 14 데이터 구조 변환 가능 여부 확인(T10)

## 7. 보관과 이용

- 원본 영상: 단기 보관 원칙
- 학습·평가용 자료: 별도 목적·동의·보관·삭제 정책(P05) 확정 전 서비스 원본에서 자동 복사 금지
- 학습된 가중치에서 특정 영상의 영향 제거 ≠ 파일 삭제 (별개 문제)

관련: 29 · 30의 D05·P05·T02~T04·T10 · 31
