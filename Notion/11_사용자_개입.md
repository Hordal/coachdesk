# 11 사용자 개입
상태: 사용자 정정 기본안

## 제공 기능
| 입력 | 처리 |
|---|---|
| 본인 선택 | 후보 트랙·대표 프레임에서 USER·OPPONENT 트랙 지정·교체·확정. 명시적 선택 전 배정 완료 처리 금지 |
| 선수 연결 정정 | 적용 시작·끝 확인, 새 Correction 생성 |
| 라운드 경계 정정 | 원본 시각 기준 기록, 시간별 집계 재계산 |
| 의도 설명 | self_report로 보관, 최초 AI 관측 유지 |
| 분석 오류 신고 | 분류: 위치·기술·수치·근거 불일치·기타 |

- 보정값 수정: 단위·출처·유효 범위 입력, 전문가 정답 취급 금지
- 임의 관절 편집: 초기 일반 사용자 기능 제외, 개발 진단 기능으로 분리
- 정정 제출 전: 적용 구간·재계산 영향 표시

## 재계산
- 관측 입력 변경 → 10의 의존 관계에 따라 새 run 생성
- 신고·의도 설명만으로 기존 계산 변경 금지, 학습 정답 자동 편입 금지
- 동시 수정: revision 검사, 오래된 수정은 충돌 안내

## 검증
- 확인 항목: 본인 오선택, 정정 취소, 중복 제출, 계산 중 정정에서도 최초 결과 보존·최신 적용 결과 명확
- 후보 두 명 미만, 선택 만료, 존재하지 않는 track_id 안내
- 같은 저장 결과 → 같은 선택 재현
- 영상 삭제 후: 근거가 필요한 재계산 요청 불가 안내

## 구현 반영
- 본인 선택: 가져온 검출·추적 결과의 후보 프레임에서 사용자가 USER·OPPONENT 트랙을 직접 선택. 사전 자동 선택 없음
- 한 선수에 트랙 여러 개 연결 가능
- 거절: 존재하지 않는 트랙, 양쪽 동시 지정, 같은 선수 트랙이 동시에 보이는 모순
- 같은 선택: 이력 미증가. 변경 시 이력 기록. 결과 재가져오기 시 지정 초기화
- 선수 연결 정정(트랙 재배정)·라운드 경계 정정: 선수 추적이 분석 흐름에 들어온 뒤 구현
- 본인 지정 정정: 새 실행 생성 + 이전 실행 연결, 최초 결과 보존, 제출 전 변경 내용·재계산 영향 표시. 이미 정정된 실행에 중복 정정 → 최신 실행 안내 후 거절
- 오류 신고·의도 설명: 계산 불변, 별도 보관
