# 06 가림과 관측 불가
상태: 결측 처리 기본안

## 기본 규칙
- 결측 구분 단위: 관절·선수·시각·지표
- 한 관절 가림 → 전체 관측 폐기 금지, 지표별 요구 입력만 검사
- 값·상태·생성 방식: 14 기준

| 상황 | 처리 |
|---|---|
| 검출 안 됨 | missing_detection |
| 몸 일부 가림 | occluded, 관련 관측·지표 보류 |
| 선수 연결 불명확 | identity_unresolved, 선수별 집계 제외 |
| 화면 밖 | out_of_frame |
| 원본 디코딩 실패 | decode_error, 시간 범위 기록 |
| 분석 범위 밖 | unsupported_segment |

- 수치 분석 기본: 보간 없음
- 시각화용 보간: 원관측과 분리, 통계 입력 사용 금지
- 보간 허용 길이: 모델·지표 실험 후 설정
- 평활화: 원데이터 덮어쓰기 금지

## 개별 판정의 독립성 — 확정
- 행동 시도·접촉 결과·반격 관계·거리 조건: 각각 별도 Assessment(14 참조)
- 예: 발차기 접촉 결과 불명확 → 뒤따른 상대 공격·직접 접촉의 유효 판정 유지
- 한 판정의 보류: 다른 독립 판정에 전파 금지, 필요 입력에 의존하는 출력에만 전파
- 구별: 관측 조건 충족한 absent / 판단 불가 unknown / 질문 비적용 not_applicable
- 가림 없음 ≠ 판정 가능 보장
- 필요한 부위·시간 정보: 02에서 정의
- 재분석 모델·횟수: 실험 후 결정

## 검증
- 장면 일부를 의도적으로 가리거나 제거: 결측이 0으로 변하지 않는지, 가림 전후 ID 임의 연결 없는지 확인
- 모델 score 임계값: 실제 자료로 선택, 고정 확률로 해석 금지
