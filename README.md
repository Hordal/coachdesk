# COACHDESK

체육관·팀의 코치와 분석 담당자가 경기·훈련 영상을 관리하고, 분석 선수를 선택해 장면을 검토하는 작업 공간입니다. FastAPI·SQLite 백엔드와 React·TypeScript 프론트엔드를 제공합니다.

## 실행하기

필요한 도구: Python 3.11 이상, Node.js 24와 npm, FFmpeg와 FFprobe.

1. FFmpeg·FFprobe가 PATH에서 실행되는지 확인합니다. 다른 위치에 설치했다면 `FFMPEG_PATH`, `FFPROBE_PATH` 환경 변수에 실행 파일 경로를 지정합니다.
2. Windows에서 `start.cmd`를 실행합니다. 처음 실행할 때 Python 환경과 화면 의존성을 설치하고 화면을 빌드합니다.
3. [로컬 코치 분석실](http://127.0.0.1:8765/)을 엽니다.
4. 내장 CPU 분석도 사용하려면 앱을 종료하고 `분석준비.cmd`를 한 번 실행한 뒤 `start.cmd`로 다시 시작합니다. Google 공식 공개 포즈 모델을 내려받아 고정 SHA-256을 대조합니다.

소스에는 사용자 영상·DB·계정 세션·비밀키·내려받은 모델·설치된 라이브러리가 들어 있지 않습니다. 새 환경에서는 영상을 직접 등록해야 합니다.

기본 실행은 이 PC에서만 접속하는 단일 사용자 모드입니다. 팀별 계정 접속과 외부 서버 운영은 [운영 안내](운영안내.md)의 인증·HTTPS 설정을 확인하세요.

## 사용 흐름

영상 등록 → 검출·추적 요청 → 사진에서 분석 선수와 상대 선택 → 동작 분석 요청 → 장면 복기·코칭 보고서 → 코치 의견 기록.

## 구현한 기능

- 영상 분할 업로드·이어 올리기·취소, 원본 해시 검사, FFmpeg 영상 준비와 프레임 탐색.
- 개인·팀 작업 공간, 선수 명부, 역할별 권한, 계정·세션 인증 모드.
- MediaPipe Pose Full 모델의 CPU 포즈 관측과 임시 인물 추적.
- 사진의 인물 상자를 눌러 선수 선택, 영상 위 관절 표시.
- 팔의 확장·복귀를 이용한 미검증 동작 후보 탐색.
- 손 위치를 측정한 규칙 기반 코칭 초안, 근거 사진·영상·조건부 연습 제안.
- 보고서에서 영상 재생·코치 메모 저장, 인쇄/PDF, 검수 이력과 정정 기록.
- 외부 모델 워커의 작업 요청·임대·취소·재시도·결과 검증, 백업과 새 경로 복구.

## 분석 범위

내장 분석은 **3분 이하·5,000프레임 이하·첫 프레임 시각 0**인 영상으로 시험할 수 있습니다. 가림과 교차로 트랙이 나뉠 수 있으므로 선수 선택은 사람이 확인합니다.

코칭 초안은 화면상 손목·어깨·골반 위치를 비교하는 시험 규칙입니다. 명중·득점·공식 채점·기술 종류·종합 경기력을 판정하는 학습 모델은 포함하지 않습니다. 후보가 없다는 것이 실제 동작이 없었다는 뜻은 아닙니다. 관측이 부족하면 평가를 만들지 않고 확인 항목을 표시합니다. 모델 학습 기능은 포함하지 않습니다.

## 개발과 시험

```powershell
# 저장소 루트: 기본 실행 환경과 화면 빌드 준비
python setup_local.py

# 서버 시험 (FFmpeg와 FFprobe 필요)
cd backend
..\.venv\Scripts\python.exe -m pytest -q

# 화면 시험과 빌드
cd ..\frontend
npm test
npm run build
```

설계와 데이터 계약은 [참조 프로젝트](https://github.com/JulidochromisRegani/MMA-Coach-Agent-SoftWare)를 참고했습니다. 이 저장소는 별도로 개발한 COACHDESK 소스이며, 원본 GitHub·Notion에는 변경을 하지 않았습니다. `Notion/02A_*.json` 등의 가상 예제는 계약 시험에 사용합니다. 운영 데이터는 `runtime/`에 생성되며 Git에서 제외합니다.
