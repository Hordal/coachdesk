# 합성 시험 자료

synthetic-demo.mp4는 색상 시험 영상입니다. 포즈·후보는 인위적으로 만든 화면·입력 검증용 데이터이며 실제 격투 동작이나 정확도·정답을 나타내지 않습니다.

영상을 올리고 같은 영상의 데이터 연결 화면에서 synthetic-poses.jsonl, synthetic-quality.jsonl, synthetic-windows.jsonl을 포즈 입력으로 선택합니다. 동작 후보에는 synthetic-actions.jsonl을 선택합니다. 다른 영상에는 시각 불일치로 거절될 수 있습니다.
